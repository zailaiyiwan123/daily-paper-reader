## 摘要
在物理世界智能快速发展的背景下，云边协同大语言模型（LLM）已成为实际部署LLM的一条有前景的路线。然而，现有云边范式难以平衡全局共识与局部个性化，无法满足云端统一知识基础与边缘领域特定适配的需求。为解决这一问题，我们首次引入个性化双层优化框架，将云边LLM协同形式化为一种双重结构：上层优化边缘侧个性化，下层管理云端知识迁移，从而实现云边协同演化。随后，我们提出CIDERS，一种高效求解器，将模型分解为可学习骨干网络和信使。云端向可学习骨干网络进行知识迁移，而关键在于通过共识变量校正将全局轨迹嵌入每个局部个性化步骤，以协调个性化与共识。我们提供了全面的理论分析，包括局部轨迹的几何刻画和完整的收敛性保证，揭示了个性化与全局收敛之间的显式权衡结构。大量实验表明，CIDERS在压缩边缘路径上持续优于有竞争力的基线，在数学推理和代码生成上分别取得3.1倍和1.7倍的增益，并在指令指标上获得10%的相对增益。机制实验将这些增益归因于早期共识校正的协调和任务感知蒸馏。总体而言，CIDERS为云边LLM系统中共识引导的持续个性化提供了一条可行路径。

## Abstract
Amid the rapid advancement of physical-world intelligence, cloud-edge collaborative large language models (LLMs) have emerged as a promising roadmap for practical LLM deployment. However, existing cloud-edge paradigms struggle to balance global consensus with local personalization, which fails to satisfy the need for a unified knowledge foundation on the cloud and domain-specific adaptation at the edge. To address this, we introduce, for the first time, a personalized bilevel optimization framework that formalizes cloud-edge LLM collaboration as a dual structure: the upper level optimizes edge-side personalization, while the lower level governs cloud-side knowledge transfer, reaching cloud-edge evolving in coordination. We then propose CIDERS, an efficient solver that decomposes the model into a learnable backbone and a messenger. While the cloud performs knowledge transfer to the learnable backbone, the key lies in embedding global trajectories into each local personalization step via consensus-variate correction to reconcile personalization with consensus. We provide a comprehensive theoretical analysis, including a geometric characterization of the local trajectory and a full convergence guarantee, revealing an explicit trade-off structure between personalization and global convergence. Extensive experiments demonstrate that CIDERS consistently outperforms competitive baselines on the compressed edge path, with 3.1x and 1.7x gains on mathematical reasoning and code generation, respectively, and a 10\% relative gain on instruction metrics. Mechanism experiments attribute these gains to early consensus-corrected coordination and task-aware distillation. Overall, CIDERS offers a viable path toward consensus-guided continuous personalization in cloud-edge LLM systems.

## 1. 核心问题与整体含义

- **研究背景**：随着 LLM 向信息处理之外的物理世界智能（CPS、具身智能等）扩展，主流云中心化架构面临结构性错配——往返网络延迟无法支撑硬实时任务；边缘数据受合规与商业限制无法上传；带宽与算力开销随 token 量与 KV-cache 流量增长；更关键的是，用户轨迹、工业日志等个性化数据产生于边缘，而所有可修改参数却集中在云端。
- **核心悖论**：现有云边协同 LLM 方案（联邦学习 + PEFT、模型分解、知识蒸馏等）本质上都以**模型共识**为设计基础，即所有边缘节点共享同一套模型参数，天然忽略了边缘数据、行为与环境本身就是个性化的。个性化与共识在局部适配器更新路径上难以共存。
- **论文主张**：首次将云边 LLM 协作形式化为**个性化双层优化（PBO）**——上层优化边缘侧个性化（信使），下层负责云端知识迁移（可学习骨干），实现"共享知识底座 + 个体演化边缘模型"的连续统一体。

## 2. 方法论

### 2.1 核心思想
- 将边缘模型分解为三个功能模块：
  - **冻结全骨干 B_F**（云端教师，保留基础语言能力）
  - **可学习骨干 B_L**（云端学生，从 B_F 蒸馏）
  - **信使 P_M**（客户端 LoRA 适配器，捕获领域个性化知识）
- 边缘模型 $M_i = P_{M,i} \circ B_L$，云端模型 $M^* = P_M \circ B_F$。

### 2.2 关键技术细节
- **压缩模型准备**：取 M* 顶部 a 层作为信使 P_M；对剩余层按均匀跨步采样得到 n' = ⌊β(n−a)⌋ 层构成 B_L（β 为压缩率）；通过 TAKD 预对齐初始化 B_L。
- **上层（个性化元目标）**：优化全局信使 w_PM 作为元模型，使其经一步内梯度更新后能快速适配各客户端：$L_{pers} = \frac{1}{N}\sum_i L_i(\tilde{w}_{PM,i}, w_{BL})$。
- **下层（任务感知知识蒸馏 TAKD）**：在公开数据上，同时对齐中间表示（MSE）、输出 logits（KL）与真实标签任务损失（ℓ_task），避免教师缺陷传播，并使 B_L 对齐下游任务流形。
- **PBO 公式**：交替优化 w_PM 与 w_BL，并加入近端项约束信使漂移。

### 2.3 算法流程（CIDERS）
1. **客户端更新**：采用**共识变量校正的几何更新**：$g_{traj} = \tilde{g}_{i,k} + \gamma(c^{(t)} - c_i^{(t)}) + \epsilon(w_{PM,i,k} - w_{PM})$。其中 γ∈[0,1] 显式参数化全局共识与本地特化之间的连续零和博弈。
2. **Hessian-Free 元优化**：提供两种策略——**FO**（直接丢弃二阶项，轻量默认）与 **FD**（中心差分 Hessian-向量估计，曲率感知）。
3. **通信压缩**：客户端仅上传**共识变量增量** Δc_i = c_i^{(t+1)} − c_i^{(t)}，云端用同步的历史状态精确重构 Δ_i,t，避免原始信使权重上传。
4. **服务器更新**：聚合全局信使与全局共识变量；固定 P_M 后执行 TAKD 更新 B_L，确保骨干表示与当前个性化上下文一致。

### 2.4 理论分析
- **收敛性**：构造 Lyapunov 函数耦合虚拟信使误差、客户端漂移、共识滞后与联合间隙，证明达到 $O(T^{-1/2})$ 次线性收敛到平稳点邻域。
- **几何刻画**：在理想化假设下证明局部轨迹的参考方向恰位于局部梯度与全局平均梯度连线上：$u_i^{(t)} = \psi_t \tilde{g}_i + (1-\psi_t)\bar{G}$，其中 $\psi_t = (1-\gamma) + \gamma(1-\alpha)^t$。
- **诊断指标**：提出 **DR**（漂移削减，$1-\psi_t$）与 **PPR**（个性化保持，$\psi_t$）两个互补度量，直接量化轨迹在个性化—共识谱上的位置。

## 3. 实验设计

### 3.1 数据集与场景
- **协议 A（下游性能与输出对齐）**：GSM8K（数学推理，1,319 题）、Dolly-15K（指令，PPL + ROUGE-L）、Rosetta/HumanEval-X（代码生成，Python/Java/Go pass@1）。
- **协议 B（匹配域个性化评估）**：五领域（医疗、金融、客服、代码、通用），每域 1,000 私有训练 + 200 公开蒸馏 + 300 评估样本，构建 5×5 响应 NLL 矩阵。
- **协议 C（非 IID 下 PBO 共识动态）**：MetaMath 45,000 样本，8 客户端，Dirichlet α=0.1/0.4（h=1/h=4），共 16,912 客户端-轮次观测。

## 6. 主要结论与发现

- **性能优势**：CIDERS 在 Qwen2-1.5B 的 6 项指标中 5 项第一，Qwen2.5-3B 全部 6 项第一。GSM8K 相对 FedBiOT 分别提升 5.30 与 11.15 个百分点（摘要中 3.1× 增益）；Dolly PPL 从 9.42 降至 8.60（约 8.7%）；代码 pass@1 提升 2.4–4.3 个百分点。
- **压缩代价**：AdapEmu→AdapFu 差距显著（如 Qwen2.5-3B GSM8K 从 16.38%→47.46%），说明更好的压缩性能并未消除小骨干的能力成本。
- **机制发现**：
  - 损失下降主要发生在早期（第 15 轮已达总降幅 74–76%），共识对齐可先于任务损失稳定。
  - 方向性个性化得以保留（S-PPR 高），但输出级特化边际很小（Δ_cross 仅 0.0176%），二者可解耦。
  - **骨干容量比信使深度对响应质量更重要**（drop ratio 从 0.2→0.5 时 NLL 从 1.754 升至 4.115）。
- **FO vs FD**：12 个 AdapEmu 单元中 9 个报告值完全相同，FD 无一致最终指标优势，故默认采用 FO。

## 7. 优点

- **理论完整性**：首次为云边 LLM 个性化双层优化建立完整理论——包含 Lyapunov 收敛保证与可解释的几何轨迹刻画，并据此设计 DR/PPR 可量化诊断指标。
