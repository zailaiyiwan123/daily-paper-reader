## 摘要
端侧大语言模型（LLM），例如在手机上运行的模型，已成熟到可通过个性化来改进。移动设备有限的计算资源限制了模型规模，进而限制模型质量，因此任何可实现的质量提升都具有很大影响。同时，其个人属性（即与特定用户的紧密耦合）意味着给定的端侧LLM往往会随时间以相似且可预测的模式被使用。本文提出一种用于个性化端侧LLM的新方法。它训练一个超网络，将用户的上下文词元映射到适合该用户的低秩适配（LoRA）。一旦训练好的通用产物部署到用户设备上，每个用户就使用该超网络（完全在设备上）合成个性化的LoRA。这种方法融合了现有两种LLM定制方法——上下文学习（ICL）和参数高效微调（PEFT）——的优点，同时避免了它们的缺点。与ICL类似（而与PEFT不同），我们方法的端侧阶段在计算上可行，仅需对神经网络进行前向传播。与PEFT类似（而与ICL不同），我们的方法通过权重（LoRA）修改“目标”基础LLM，避免了扩展输入序列所带来的负面后果（例如延迟增加）。我们的方法特别适合移动设备场景。除上述端侧计算和延迟优势外，它还需要极少的额外存储，因为其架构内部部分复用了属于待个性化目标LLM的相同LLM权重。我们在多个代表性个性化数据集上展示了LoRA生成超网络的优势，并与ICL和PEFT等基线进行了比较。值得注意的是，我们的个性化实验聚焦于更具挑战性且研究较少的长文本生成任务。

## Abstract
On-device large language models (`LLMs'), e.g. running on mobile phones, are ripe for improvement via personalization. The limited compute resources of mobile devices impose limits on model scale and thus model quality, making any realizable quality gains highly impactful. At the same time, their personal nature (i.e., the close coupling to a particular user) means that a given on-device LLM tends to be used in similar, predictable patterns over the course of time. This paper presents a novel method for personalizing on-device LLMs. It trains a hypernetwork to map a user's context tokens to a low-rank adaptation (`LoRA') well-suited to that user. Once the trained common artifacts are deployed to users' devices, each user uses the hypernetwork to synthesize (entirely on device) a personalized LoRA. This approach blends the benefits while avoiding the drawbacks of two existing approaches to LLM customization: in-context learning (`ICL') and parameter-efficient fine-tuning (`PEFT'). Like ICL (and unlike PEFT), the on-device phase of our approach is computationally feasible, requiring only forward passes through neural networks. Like PEFT (and unlike ICL), our approach modifies the `target' base LLM via weights (the LoRA), avoiding negative consequences (e.g. increased latency) associated with extending the input sequence. Our approach is particularly well-suited to the mobile device regime. Apart from the on-device compute and latency benefits mentioned, it also requires minimal additional storage, as internally its architecture partly leverages the same LLM weights as belong to the target LLM to be personalized. We demonstrate the benefits of LoRA-generating hypernetworks on several representative personalization datasets, comparing against baselines like ICL and PEFT. Of note, our personalization experiments focus on more challenging and less studied long-form text generation tasks.

# 论文总结：用于高效端侧 LLM 生成式个性化的 LoRA 生成超网络

## 1. 核心问题与整体含义

- **背景**：端侧 LLM（如手机端运行的模型）因移动设备算力/存储受限，模型规模小、能力受限，因此任何可实现的性能提升都很有价值。
- **机会**：手机通常由单一用户使用，使用模式长期稳定且可预测（写作风格、语气等），这为长期个性化提供了机会。
- **核心问题**：如何在端侧算力约束下实现 LLM 的生成式个性化？现有两大范式均有明显缺陷：
  - **PEFT（如 LoRA）**：需要梯度下降，在手机上计算上不可行（内存需求远高于推理）。
  - **ICL**：只做前向传播可行，但增加输入序列长度导致推理延迟上升；且随上下文增长质量下降（“context rot”），还存在首尾位置偏置问题。
- **整体含义**：本文提出 LoRA 生成超网络，融合 ICL 的可行性（仅前向）与 PEFT 的权重修改优势（不扩长输入），把重计算上移到一次性、可摊销的 Phase 1，从而在端侧实现高效个性化。

## 2. 方法论

### 核心思想
训练一个超网络，将用户的上下文 token 映射为适合该用户的 LoRA 矩阵；部署后每个用户完全在设备端前向生成个性化 LoRA，附加到目标 LLM 上。

### 三阶段流水线
- **Phase 1（通用产物创建，一次性、离线）**：训练超网络，产出嵌入器 LoRA 与 embedding-to-matrix MLP 权重，分发给所有设备。
- **Phase 2（个人产物创建，每用户一次、端侧）**：用户上下文输入超网络，前向合成个性化 LoRA 并存储。
- **Phase 3（个性化推理，每查询、端侧）**：将个性化 LoRA 附加到目标 LLM，产生个性化响应。

### 关键技术细节
- **复用目标 LLM**：以端侧已有的冻结目标 LLM 作为文本编码器基底，附加可学习的**嵌入器 LoRA**（rank r 为超参数），将其转为定制文本编码器（借鉴 LLM2Vec）。
- **池化**：对 LLM 输出序列做均值池化（仅含非 padding 位置），得到单一用户嵌入向量。
- **embedding-to-matrix MLP**：一组并行的 2 层前馈块，每个将用户嵌入映射为一个 LoRA 的 A 或 B 矩阵（对应目标 LLM 的某层某模块）。
- **瓶颈设计**：中间向量维度 k 远小于输入嵌入与输出 LoRA 矩阵，可解释为“主/特征低秩矩阵”的系数；k 类比于 SVD 保留的奇异值个数。
- **输入形式**：上下文示例可批量并行或拼接为单序列，实验发现拼接更有效。
- **可删除性**：LoRA 生成后，超网络的额外参数可从设备删除。

### 训练流程
- **两阶段训练**：
  1. **LLM2Vec 式预训练**：对嵌入器 LoRA 做无监督对比学习，使用户在隐空间可分（基于 SimCSE）。
  2. **端到端训练**：采样用户队列，每用户取两批不相交数据（一批作超网络输入，一批作目标 LLM 输入/标签）；生成 LoRA 后附加到目标 LLM，计算 token 交叉熵损失，对超网络可训练参数反向传播。
- **蒸馏**：用 ICL 作为教师做 context distillation（持续展示不同用户上下文），对训练有显著增益；附录中对比了 L1 正则化的替代方案。

## 3. 实验设计

### 数据集 / 场景（均为“用户分区”数据集，训练/测试用户不相交）
- **LongLaMP-3（Amazon 评论写作）**：根据产品摘要与描述生成用户个性化深度评论，长文本。
- **LongLaMP-4（Reddit 帖子写作）**：根据帖子摘要生成体现用户风格与兴趣的帖子内容，长文本。
- **LaMP-5（学术标题写作）**：为论文生成体现研究者学术兴趣的标题，序列较短。

### Benchmark 与指标
- 以 **ROUGE-1** 为主要质量指标，同时报告 token 交叉熵。
- 评估两个维度：**用户平均 ROUGE-1**（改进深度）与**相对单 LoRA 基线改进的用户百分比**（改进广度）。
- 对 T=1.0 的数据集每个查询生成 10 次取平均以降噪；对每个方法/数据集扫描温度 T 选最优（LongLaMP-3/4 为 1.0，LaMP-5 为 0.0 贪心）。

### 对比方法
- **No LoRA 基座 LLM**（非个性化）
- **单 LoRA（非个性化基线）**
- **单 LoRA + per-user ICL**（MetaICL 式，仅微调 LoRA）
- **PEFT per-user LoRA**：每用户从单 LoRA 初始化，Adam 微调两步
- **Hypernetwork per-user LoRA**（本文方法）

### 配置
- 基础模型：**Gemma 3-1B-IT** 与 **Gemma 1-2B-IT**。
- LoRA rank：**4 与 32**；仅生成/应用注意力相关矩阵的 LoRA（实现选择，超网络本身可生成 FFN 的 LoRA）。
- 各方法在个性化推理时使用相同 rank 的 LoRA，以保证可比性。

## 6. 主要结论与发现

- **超网络生成的 LoRA 在几乎所有场景下取得最佳（或接近最佳）的 ROUGE-1**，优于 ICL 与 PEFT 基线。
- **LongLaMP-3/4**：多数配置下超网络为超过 3/4 的用户带来 ROUGE-1 改进；改进广度明显优于 PEFT 与 ICL。
- **LaMP-5 对所有方法都难个性化**，超网络仍略有优势。
- **有趣现象**：ICL 在最小化交叉熵上最好，但在最大化 ROUGE-1 上最差；提高温度未进一步改善 ROUGE-1。
- **上下文错配实验**：错配后 ROUGE-1 低于所有方法（甚至低于非个性化基线），证明超网络确实在利用用户上下文信号。
- **正则化替代方案**：L1 正则化训练的超网络 ROUGE-1 接近蒸馏版，但交叉熵明显更好。

## 7. 优点

- **方法设计亮点**：
  - 巧妙复用端侧已有的目标 LLM 权重作为编码器，显著降低额外存储（额外参数仅约 1400 万–1.1 亿，相对 10 亿/25 亿基座模型很小）。
  - 端侧仅需前向传播即可生成个性化 LoRA，兼顾 ICL 的可行性与 PEFT 的权重修改优势。
  - 不增加输入序列长度，保留上下文窗口给对话记录/RAG 等其他用途。
  - LoRA 生成后可删除超网络参数，节省设备存储。
- **实验设计亮点**：
  - 聚焦更具挑战性、研究较少的长文本生成个性化任务。
  - 同时报告改进深度（均值）与广度（改进用户百分比），评估维度全面。
  - 上下文错配实验有效验证了方法的因果机制。
  - 训练/测试用户不相交，检验个性化泛化能力。
