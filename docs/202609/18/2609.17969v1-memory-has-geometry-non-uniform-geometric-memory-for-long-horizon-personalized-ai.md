## 摘要
长期记忆正成为个性化AI的核心基础，但大多数系统仍将个性化表示为基本静态的潜在空间中的离散记录，并在单一全局相似性概念下进行访问。对数据挖掘而言，这造成了错配：证据是时间事件流，而主流抽象是可搜索的记录集合。我们认为，长时程个性化应转而将记忆建模为具有局部异质几何的用户特定动态状态空间。这里的几何是一种计算语言，而非对认知的字面主张：它刻画稳定区域与易变区域、变速率漂移、异质邻域，以及关于当前用户状态的不确定性。画像和孤立事件仍可作为点有用，但交互、反馈和流逝时间会诱导轨迹。于是记忆访问成为对相关用户状态的轨迹条件化重建，而不仅仅是最近邻查找。

## Abstract
Long-term memory is becoming a core substrate for personalized AI, yet most systems still represent personalization as discrete records in a largely static latent space, accessed under one global similarity notion. For data mining, this creates a mismatch: the evidence is a temporal event stream, while the dominant abstraction is a searchable record set. We argue that long-horizon personalization should instead model memory as a user-specific dynamical state space with locally heterogeneous geometry. Geometry here is a computational language, not a literal claim about cognition: it captures stable versus volatile regions, variable-rate drift, heterogeneous neighborhoods, and uncertainty about current user state. Profiles and isolated events remain useful as points, but interaction, feedback, and elapsed time induce trajectories. Memory access then becomes trajectory-conditioned reconstruction of the relevant user state, not only nearest-neighbor lookup.

## 2. 方法论：核心思想与关键技术细节

### 2.1 核心思想

- 将个性化记忆建模为**用户特定的几何动力系统**：一个状态空间，其局部度量结构、曲率、尺度与不确定性随区域变化并随交互演化。
- **几何是计算语言，不是对认知的字面主张**：用于刻画稳定区 vs 易变区、变速率漂移、异质邻域、当前用户状态的不确定性。
- 画像与孤立事件仍可作为"点"，但**交互、反馈与流逝时间诱导轨迹**。记忆访问从最近邻查找转为**轨迹条件化的用户状态重建**。

### 2.2 形式化框架

- **状态空间**：$(M, G)$，其中 $M$ 为流形式状态空间，$G=\{g_x\}_{x\in M}$ 是正定局部度量场，编码尺度与各向异性；曲率由度量变化导出，不确定性单独建模。
- **状态与事件**：用户记忆状态为点 $x_t \in M$；事件 $e_t=(o_t, \Delta t_t)$ 含交互证据与流逝时间。
- **动力学更新**：$x_t = \mathrm{Exp}_{x_{t-1}}\big(g^{-1}_{x_{t-1}} f_\theta(x_{t-1}, e_t)\big)$，即 $f_\theta$ 在切空间提出切余向量，逆度量将其转换为位移，再经指数映射回到流形。当度量为恒等时退化为**加性欧氏更新**。度量与状态的后验表示认知不确定性；**更新速率单独学习**（类似连续时间动力学）。
- **关键辨析**：高曲率本身**不**意味着快速漂移。
- **基本对象是轨迹族** $\Gamma=\{\gamma_k\}$，每条路径刻画一段连贯的用户状态演化（偏好机制、项目、日常、情节）。
- **访问范式对比**：
  - 记录中心检索：$R(q_t, D_t) = \mathrm{TopK}_{m_i \in D_t} s(q_t, m_i)$
  - 几何记忆重建：$\hat r_t = \int h_\theta(q_t, x_t, z)\, p(z \mid q_t, x_t, \Gamma)\, dz$，其中 $z$ 为相关路径片段；$\hat r_t$ 可驱动生成、推荐、行动、适应、置信度或弃答。

### 2.3 研究版图（Table II 的两层七方向）

## 6. 主要结论与发现

- 长时程个性化的记忆瓶颈是**抽象层面的错配**，而非检索精度不足；记录-检索范式与时间事件流证据之间存在根本张力。
- 提出**非均匀几何记忆**作为统一框架，整合用户状态、轨迹、局部度量、不确定性与可控干预，使**持久偏好、临时上下文与机制切换得以共存**。
- 记忆访问应由 Top-k 邻居查找转为**轨迹条件化的状态重建**，从而支持一致适应、可解释决策与定向编辑/遗忘。
- 该框架连接时间数据挖掘、几何学习、推荐系统与个性化智能体；模块化组件可使用标准反馈，先经离线回放与影子部署评估校准、延迟与编辑局部性，再行上线，构成通向持久个性化智能的实用路径。
