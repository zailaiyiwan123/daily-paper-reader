## 摘要
我们采用认知模拟视角研究多项选择问答中的情景记忆与语义记忆，方法是将个体文本语料库（ITC）中的文本纳入检索增强生成和DoRA微调。我们网络爬取了515名参与者的搜索历史，这些参与者回答了36个多项选择知识题项，并分析了150名参与者的分层子样本。对于每位参与者，一个DoRA适配器将其ITC整合到一个小型语言模型（SLM）中，该模型的基线正确率低于参与者的最低四分位数。该适配器以可测量的方式将ITC写入权重：它对自己参与者的留出文本的拟合优于其他参与者的文本（dz = 1.27），这种个体性效应随ITC规模按秩序增大而增强。然而，在泛化知识测试上，适配器增加的是知识，而不是与个体的对齐：对数损失匹配得到改善，而在偏差校正的PMI读出下的匹配准确率没有改善，且检索没有在此基础上带来任何增益。我们的结果表明，ITC可以被整合到SLM的权重中，这为个体化辅导智能体提供了令人鼓舞的基础；我们还讨论了如何从那里迈向个体层面情景记忆与语义记忆的现实模拟。

## Abstract
We approach a cognitive simulation perspective on episodic and semantic memory in multiple-choice question answering by incorporating text from individual text corpora (ITC) into retrieval-augmented generation and DoRA fine-tuning. We web-crawl the search histories of 515 participants who answered 36 multiple-choice knowledge items and analyze a stratified subsample of 150 participants. For each participant, one DoRA adapter consolidates their ITC into a small language model (SLM) whose baseline correctness falls below the participants' lowest quartile. The adapter measurably writes the ITC into the weights: it fits its own participant's held-out text better than other participants' texts (dz =1.27), an individuality effect that increases with ITC size in rank order. On the generalized knowledge test, however, the adapter adds knowledge rather than alignment with the individual: log-loss match improves, whereas match accuracy under a bias-corrected PMI readout does not, and retrieval adds nothing on top. Our results demonstrate that ITCs can be consolidated into the weights of SLMs, an encouraging basis for individualized tutoring agents, and we discuss how to move from there toward a realistic simulation of episodic and semantic memory at the individual level.

# 论文总结：从检索到权重——基于个体文本语料库的小型语言模型参数化个体化

## 1. 核心问题与整体含义

- **研究动机**：认知科学与 NLP 长期关注从语言模型中"复现或提取"人类知识，但绝大多数工作停留在**群体层面**（如从词/文本嵌入中恢复聚合知识、把 LM 当作通用认知被试）。然而个体间知识差异极大，如何在**个体层面**模拟"这个人知道什么"仍是一个开放挑战。
- **理论背景**：
  - 图尔文（Tulving）的**情景记忆 vs. 语义记忆**区分：语义记忆存储一般事实，情景记忆存储个人经历事件。
  - 晶体智力（Gc）与 OFCI 模型：开放性驱动人寻求刺激环境 → 强化流体能力 → 构建晶体智力；互联网被视为一种"环境富集"，而**个人搜索历史**记录了其知识构建所接触的内容。
- **问题定位**：前作（Wigbels et al., 2026）用 316 名参与者的 Google 搜索历史 + RAG 预测其选择题答案，发现了可检测的个体信号但校准很差。本文将问题重构为**参数化个体化**：不再把个体文本语料（ITC）放在外部检索库中，而是通过 DoRA 微调把它**写入模型权重**。
- **类比**：RAG 对应"情景步骤"（推理时提供上下文），把 ITC 固化进权重对应"语义步骤"（记忆巩固，McClelland et al., 1995 的互补学习系统理论）。
- **三条假设**：
  - **H1 参数化个体化**：加入个体适配器可提升与参与者答案的匹配（match accuracy ↑、log-loss match ↓）。
  - **H2 适配 vs. 检索**：适配器与检索通过不同路径达到个体信号，其效应不一定可加；检验二者交互（替代 or 互补）。
  - **H3 ITC 规模鲁棒性**：在统计控制 ITC 规模后，适配器与检索效应仍然存在。

## 2. 方法论

### 2.1 核心思想

- 以 **Qwen3-0.6B** 为冻结基座（bfloat16），为**每位参与者训练一个专属 DoRA 适配器**，通过对该参与者清理后的 ITC 做**原始持续预训练（raw continued pretraining）**，把其个人知识分布写入低秩权重更新。
- 基座模型持有跨参与者共享的通用知识，适配器承载个体独有信息——这正是"情景经验巩固为语义记忆"的参数化对应物。
- **测量视角的转变**：从"答案接口"（选项 ID 的 first-token 概率）转向"答案内容"（选项文本的似然）。因为原始持续预训练得到的适配器**本质上不是指令跟随者**，ID 读法会失效（对照实验中适配器在 ID 读法下仅处于随机水平）。

### 2.2 关键技术细节

- **ITC 构建流程**：
  - 参与者通过 Google Takeout 导出搜索历史 → 提取访问 URL 列表。
  - 两遍爬取管线：第一遍 HTTP 抽取 + 第二遍 JavaScript 渲染，均经轮换代理，支持 PDF。
  - 清洗过滤：去模板/样板内容、丢弃非德语文本（少于 3 个德语停用词的句子被剔除）；英文内容先用 NLLB 机器翻译为德语再保留；去重（重复访问的页面不重复计入）。
- **DoRA 适配器配置**：
  - 秩 `r=16`，`α=32`，dropout 0.05，作用于**所有线性模块**。
  - 学习率 `1.5×10⁻⁴`，5% warmup 后恒定；paged 32-bit AdamW；有效 batch size 为 24 条 × 2048 token 的序列；bf16。
  - 无任何合成数据增强；文档级种子化 train/held-out 划分；按 held-out loss 早停（epoch 上限 10，patience 3）。
- **评分与读出（Evaluation）**：
  - 每个选项按**长度归一化序列似然**（选项文本在问题提示下的平均逐 token 对数似然）打分，再在四个选项上重归一化为答案分布。
  - **主评分视角**：领域条件点互信息（PMI）变体——额外减去该选项在**中性空提示**（"Antwort:"）下的平均逐 token 对数似然，以去除对通用选项字符串的偏好；LN（长度归一化）似然作为**鲁棒性视角**。
  - **三个基准**（沿用前作定义，但改在选项内容上操作化）：
    - **match accuracy**：模型最可能选项等于参与者答案的比例。
    - **log-loss match**：参与者所选选项的负对数概率。
    - **CK-accuracy**：模型最可能选项的**正确性**与参与者答案正确性一致的比例。
  - **置换平衡对照库**：小型合成题集，每个选项在每个位置出现次数相等，用于验证读出是内容驱动的（基座控制准确率 0.50，适配器 0.70–0.72，随机水平 0.25）。
- **检索设置**：用 nomic-embed-text-v1.5 对 ITC 分块做稠密检索，取 top-5 块插入问题之前；所有提示以中性线索"Antwort:"结尾，不使用 chat template；同一参与者同一题项在基座与适配器臂中检索到的上下文完全相同。
- **文本级"注入检查"**：
  - `g_own`：本适配器相对基座模型在**本人留出文档**上的逐 token NLL 下降。
  - `g_foreign`：本适配器在 **20 名种子伙伴参与者**留出文档上的逐 token NLL 下降。
  - **个体性对比** = `g_own − ḡ_foreign`，仅在适配器能超越任何通用增益地拟合本人未见文本时才为正。
- **答案级分解**（按参与者答对/答错分项）：
  - **knowledge gain**：在答对题项上，正确选项的 δ 减去三个错误选项的平均 δ。
  - **chosen-option mass**：在答错题项上，参与者实际所选选项的 δ。
  - **error alignment**：上述 δ 再减去另外两个错误选项的平均 δ——只有在适配器朝该参与者**特定错误**（而非泛化的合理干扰项）移动时才为正。
- **统计方法**：所有检验在参与者内配对（逐题分数先按参与者与单元格平均，再检验人均差异）；Shapiro–Wilk 检验选择 t 检验或 Wilcoxon 符号秩检验；报告 within-subject Cohen's `dz`；H2 交互按参与者在两种检索条件下的适配器效应之差计算；H3 用每名参与者的对比与 `log10 ITC size` 做 Pearson 与 Spearman 相关，并做规模偏相关控制。
