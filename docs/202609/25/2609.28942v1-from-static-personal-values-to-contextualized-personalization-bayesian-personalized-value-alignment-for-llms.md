## 摘要
随着大语言模型（LLMs）被期望适应多样化的用户偏好，个性化价值对齐已变得越来越重要。然而，现有方法通常使模型输出在不同提示下都与静态价值画像对齐，忽略了价值维度的重要性会因情境不同而显著变化。受勒温场论（Lewin's Field Theory）启发，该理论认为人类行为由个人倾向与情境约束共同塑造，我们将个人价值观建模为先验，将情境依赖的偏好建模为后验。我们提出 BaCVA，一种推理时的贝叶斯情境感知个性化价值对齐方法，通过将静态个人价值观与场景特定的价值显著性相结合，来近似后验的个性化偏好。BaCVA 首先从一般规范性回答中估计情境价值显著性，然后采用双视角个性化模块，从互补的个人价值观视角和情境驱动视角推断后验偏好。这种贝叶斯形式能够实现更准确且更具适应性的个性化价值对齐，同时通过先验价值观提高数据效率。在基准上的大量实验表明其优于强基线。

## Abstract
Personalized value alignment has become increasingly important as large language models (LLMs) are expected to accommodate diverse user preferences. However, existing methods typically align model outputs with a static value profile across prompts, overlooking that the salience of value dimensions varies substantially across contexts. Inspired by Lewin's Field Theory, which views human behavior as jointly shaped by personal dispositions and situational constraints, we model personal values as priors and context-dependent preferences as posteriors. We propose BaCVA, an inference-time Bayesian Context-aware personalized Value Alignment method that approximates posterior personalized preferences by integrating static personal values with scenario-specific value salience. BaCVA first estimates contextual value salience from generally normative responses, and then employs a dual-view personalization module to infer posterior preferences from complementary personal-value and scenario-driven perspectives. This Bayesian formulation enables more accurate and adaptive personalized value alignment while improving data efficiency via prior values. Extensive experiments on benchmarks demonstrate its superiority over strong baselines.

## 1. 核心问题与整体含义（研究动机与背景）

- **背景**：LLM 的通用价值对齐（如 HHH：helpful/harmless/honest）追求单一、普适的价值标准，难以容纳个体用户之间巨大的价值差异，因此"个性化价值对齐"成为更实际的目标。
- **现有方法的划分**：
  - *训练时方法*（VPL、RLPA、P-RLHF 等）：依赖大量用户交互数据微调个性化奖励模型或适配器，在数据稀缺或冷启动场景下性能退化。
  - *推理时方法*（ValuePrompt、COUPLE、ValuesRAG、PAD、MOD 等）：通过提示、激活参数或改写解码分布来引导输出，灵活性更高。
- **核心痛点（论文的关键批评）**：几乎所有推理时方法都把个性化理解为"让输出贴合一份**静态**用户价值画像"，即对所有问题复用同一份画像；虽然条件化于输入问题，但**未显式建模"哪些价值维度在当前情境下变得更显著或更不重要"**。
- **理论依据**：受勒温场论（行为 = 个人倾向 × 情境约束）与认知评价理论启发，论文认为可观察行为由**个人价值画像**与**情境价值显著性**共同塑造。例如一个本质上"自我导向 > 顺从"的用户，在严格规程的紧急事件中仍可能选择顺从。
- **形式化视角**：将固有个人价值观与情境价值显著性视为**互补先验**，将观测行为推断出的价值视为**后验**；个性化对齐由此被重构为**上下文感知的后验推断问题**。
- **两大预期收益**：① 细粒度自适应（捕捉跨情境的价值偏移）；② 数据高效（高质量先验降低训练样本需求，并易于泛化到新用户）。

## 2. 方法论：核心思想、关键技术细节与流程

### 2.1 任务定义
- 用户集合 \(U=\{u_i\}\)，每个用户有自述价值摘要 \(c_{u_i}\) 与少量偏好标注 \(D_{u_i}=\{(x, y^c, y^r)\}\)。
- 将开放式摘要转换为结构化多维价值画像 \(v_{u_i}=[(v_1,s_1),...,(v_d,s_d)]\)，维度取自 Schwartz 基本价值观（如自我导向、权力、仁爱等），\(s_j\in\{1,...,5\}\) 为 5 点 Likert 优先级。
- 目标：用单一共享模型推断问题特定的个性化价值 \(v_{u_i,x}\sim p_\theta(v|v_{u_i},x)\)，以引导回答生成。

### 2.2 贝叶斯建模
- 将偏好事件 \(o:=(y^c\succ y^r)\) 作为似然，后验写为：
  \[
  p_\theta(v_{u,x}\mid v_u,x,y^c\succ y^r)\propto p_\theta(y^c\succ y^r\mid v_{u,x})\times p_\theta(v_{u,x}\mid v_u,x)
  \]
- 由于后验不可直接计算（多维 5 点向量的精确边缘化代价过高），采用**变分推断**引入变分后验 \(q_\phi(v_{u,x}|v_u,x)\)，优化目标为最大化 ELBO：
  \[
  \mathcal{L}=-\mathbb{E}_{q_\phi}[\log p_\theta(y^c\succ y^r\mid v_{u,x},x)]+\mathrm{KL}(q_\phi(v_{u,x}\mid v_u,x)\,\|\,p_\theta(v_{u,x}\mid v_u,x))
  \]

### 2.3 三大组件
- **（i）情境价值估计器（Scenario Value Estimator）**：
  - 用经过充分人类对齐的 LLM（实现中用 GPT-5-nano）针对问题 \(x\) 生成"通用规范回答" \(y^{human}\)。
  - 通过提示式价值估计器 \(q_\omega\) 推断情境价值显著性分布：\(v_x\sim q_\omega(\cdot\mid x,y^{human})\)。其直觉是：具体问题只激活部分价值维度，且这种显著性由普遍社会规范塑造。
- **（ii）双视角个性化模块（Dual-View Personalization）**：从两个互补视角近似后验。
  - **视角一：情境锚定的个性化漂移**——以场景显著性为先验锚点，在 logit 空间加入个人残差：
    \[
    q_\phi(v^{(x)}_{u,x}\mid v_x,v_u)=\mathrm{Softmax}(s_x+z_u),\quad s_x=\mathrm{Logit}(q_\omega(v_x))
    \]
    适用于"多数人遵循场景共识、仅带轻微个性化偏离"的情形。
  - **视角二：个人锚定的情境实例化**——以个人价值先验为起点，在 logit 空间加入情境残差：
    \[
    q_\phi(v^{(u)}_{u,x}\mid v_u,v_x)=\mathrm{Softmax}(s_u+z_x),\quad s_u=\mathrm{Logit}(q_\phi(v_u))
    \]
    适用于"个人价值主导、场景约束较弱"的情形。
  - 残差并非显式采样，而是通过提示构造情境语义表示，再经轻量投影网络在 logit 层生成修正量。
- **（iii）情境感知门控融合（Context-Aware Gated Fusion）**：
  - 最终后验为两视角的加权组合：\(q_\phi(v_{u,x}\mid v_u,x)=\alpha q_\phi(v^{(x)})+(1-\alpha)q_\phi(v^{(u)})\)。
  - 门控系数 \(\alpha\in[0,1]\) 由 LLM 实现的门控函数 \(G(x, q^{(x)}, q^{(u)}, \sigma^2_{v^{(x)}}, \sigma^2_{v^{(u)}})\) 输出，通过归一化 token "0" 与 "1" 的 logits 得到连续权重（而非硬二值决策），输入中包含两视角的后验方差以表征不确定性。

### 2.4 训练目标（实用实现）
- 用同一价值提取器分析偏好回答得到监督信号 \(v_{y^c}\)，用单次摊销估计近似期望项，损失为：
  \[
  \mathcal{L}=\|\hat{v}_{u,x}-v_{y^c}\|_2^2+\lambda_1\sum_{k\in\{u,x\}}\mathrm{KL}(q^{(k)}_\phi\|p^{(k)}_\theta)
  \]
- 即"价值回归损失 + 双视角 KL 正则"，\(\lambda_1\) 控制先验正则强度。

### 2.5 端到端扩展（BaCVA-E2E）
- 将推断出的价值向量经线性投影映射为 \(k=8\) 个软提示（soft prompt）前缀嵌入，与问题、回答拼接。
- 联合目标：\(\mathcal{L}_{E2E}=\mathcal{L}_{value}+\lambda\mathcal{L}_{gen}\)，其中生成损失采用 DPO 风格的多线对齐目标，\(\pi_{ref}\equiv 0\)、\(\lambda=1.0\)、\(\beta=0.1\)。推理时仍采用与两阶段相同的离散文本提示，以隔离"价值推断改进"与"解码接口改变"带来的增益。

  - **潜在不足**：Accuracy 指标仅 PRISM 可用；人类评估样本量较小（50 条）；部分关键基线（如训练时方法）仅在附录对比；所有结果基于离线数据，缺少在线/真实部署验证。

## 6. 主要结论与发现

- **个性化是必要的**：所有个性化方法显著优于非个性化 DirectAnswer，说明通用对齐无法覆盖个体偏好多样性。
- **静态画像次优**：PersonValue 在 PRISM 上仅 56.56% 准确率，印证"跨提示复用固定画像"的根本局限。
- **BaCVA 全面最优**：

  - GOOD：MAE 1.118、Correlation 0.769；
  - 也优于训练时对齐方法（RLHF、MORLHF）。
