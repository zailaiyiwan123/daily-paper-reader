## 摘要
长期记忆正成为个性化AI的核心基础，但大多数系统仍将个性化表示为 largely static 潜在空间中的离散记录，并以单一全局相似性概念进行访问。对于数据挖掘而言，这造成了一种错配：证据是时序事件流，而主流抽象却是可搜索的记录集合。我们认为，长时程个性化应转而将记忆建模为具有局部异质几何的用户特定动态状态空间。这里的几何是一种计算语言，而非关于认知的字面主张：它刻画稳定区域与易变区域、变速漂移、异质邻域，以及关于当前用户状态的不确定性。画像和孤立事件作为点仍然有用，但交互、反馈和流逝时间会诱导出轨迹。于是，记忆访问就变成了对相关用户状态的轨迹条件重构，而不仅仅是最近邻查找。

## Abstract
Long-term memory is becoming a core substrate for personalized AI, yet most systems still represent personalization as discrete records in a largely static latent space, accessed under one global similarity notion. For data mining, this creates a mismatch: the evidence is a temporal event stream, while the dominant abstraction is a searchable record set. We argue that long-horizon personalization should instead model memory as a user-specific dynamical state space with locally heterogeneous geometry. Geometry here is a computational language, not a literal claim about cognition: it captures stable versus volatile regions, variable-rate drift, heterogeneous neighborhoods, and uncertainty about current user state. Profiles and isolated events remain useful as points, but interaction, feedback, and elapsed time induce trajectories. Memory access then becomes trajectory-conditioned reconstruction of the relevant user state, not only nearest-neighbor lookup.

## 2. 方法论：核心思想与关键技术细节

### 2.1 核心思想：几何记忆作为动力系统

- 把个性化记忆建模为**几何动力系统**：一个用户特定的状态空间，其局部度量结构、曲率、尺度与不确定性随区域变化并随交互演化。
- 形式化定义：设 $(M, G)$ 为个性化记忆状态空间，其中 $M$ 是流形状状态空间，$G = \{g_x\}_{x \in M}$ 是正定局部度量场，编码尺度与各向异性；曲率由度量变化导出，不确定性单独建模。
- 用户 $t$ 时刻的记忆状态为点 $x_t \in M$；事件 $e_t = (o_t, \Delta t_t)$ 包含交互证据 $o_t$ 与流逝时间 $\Delta t_t$。

### 2.2 状态更新公式（文字说明）

- 给定状态 $x_{t-1}$ 与事件 $e_t$，记忆演化为：
  $$x_t = \mathrm{Exp}_{x_{t-1}}\left(g^{-1}_{x_{t-1}} f_\theta(x_{t-1}, e_t)\right)$$
- 其中 $f_\theta$ 在切空间提出一个**切余向量**（tangent covector），逆度量 $g^{-1}$ 将其转换为位移，再经指数映射 $\mathrm{Exp}$ 回到流形。
- **特例**：若度量为恒等度量，该式退化为欧氏空间中的加性更新——说明几何记忆是传统更新方式的推广。
- 更新速率（update rate）**单独学习**，类似连续时间动力学（Neural ODE 思路）；论文强调**高曲率本身并不蕴含快速漂移**，二者应解耦。

### 2.3 记忆访问：从检索到轨迹条件重建

- **轨迹族**：基本对象是 $\Gamma = \{\gamma_k\}$，每条路径刻画用户状态的连贯演化（偏好 regime、项目、日常惯例、情节）。
- **记录式访问（旧范式）**：$R(q_t, D_t) = \mathrm{TopK}_{m_i \in D_t} s(q_t, m_i)$，即在单一相似度下取 top-k 邻居。
- **几何记忆访问（新范式）**：$\hat{r}_t = \int h_\theta(q_t, x_t, z)\, p(z \mid q_t, x_t, \Gamma)\, dz$，其中 $z$ 为相关路径片段。
- $\hat{r}_t$ 可驱动响应生成、推荐、动作、适应、置信度输出或**弃权（abstention）**。
- **概念转变**：记忆访问变成"对轨迹的推断"，而非"对条目的查找"。

## 6. 主要结论与发现

- **核心主张**：长时程个性化记忆应从"可检索记录集"推进为"**动态几何状态空间**"，记忆访问应从最近邻查找变为**轨迹条件的状态重建**。
- **范式对比（表 I）**：

  |---|---|---|
