## 摘要
大语言模型正日益被用作个性化写作助手，但让模型适配众多作者可能会损害个体写作风格，将作者特有的信号拉向一种共享语域。联邦参数高效微调（PEFT）为这一多作者适配问题提供了一种数据本地化设置：客户端将作者文本保留在本地，同时共享紧凑的适配器更新。然而，我们表明，标准聚合可以在保持续写效用的同时，使不同作者的生成结果在风格空间中更难区分，我们将这一失效模式定义为作者风格同质化。我们在主要 BlogText 基准上使用基于角度风格分类编码器（ASCE）的诊断方法，并结合不依赖 ASCE 的外部作者身份验证，来评估作者风格保留。使用该协议，我们发现常见的联邦 PEFT 基线能够保持语义效用，却会平均掉作者特有的信号。为解决这种同质化，我们实例化 FAVoR（联邦作者声音保留），一种面向联邦 PEFT 的作者风格残差机制。FAVoR 采用共享-私有适配器设计：客户端上传共享适配器更新，同时在本地保留作者特有的残差修正。在 BlogText 和外部 Mythos-Reddit 验证上，FAVoR 相比标准和个性化联邦 PEFT 基线提升了作者风格保留。这些增益以小幅续写效用折衷为代价，并得到组件消融、外部验证和冷启动迁移的支持。

## Abstract
Large language models are increasingly used as personalized writing assistants, but adapting a model across many authors can compromise individual writing style by pulling author-specific signals toward a shared register. Federated parameter-efficient fine-tuning (PEFT) offers a data-local setting for this multi-author adaptation problem: clients keep author text local while sharing compact adapter updates. However, we show that standard aggregation can preserve continuation utility while making different authors' generations less distinguishable in style space, a failure mode we define as author-style homogenization. We evaluate author-style retention with Angular Style Classification Encoder (ASCE)-based diagnostics on our main BlogText benchmark and ASCE-independent external authorship verification. Using this protocol, we find that common federated PEFT baselines can preserve semantic utility while averaging out author-specific signals. To address this homogenization, we instantiate FAVoR (Federated Authorial Voice Retention), an author-style residual mechanism for federated PEFT. FAVoR uses a shared-private adapter design: clients upload shared-adapter updates while retaining author-specific residual corrections locally. Across BlogText and external Mythos-Reddit validation, FAVoR improves author-style retention over standard and personalized federated PEFT baselines. These gains come with small continuation-utility trade-offs and are supported by component ablations, external verification, and cold-start transfer.

# FAVoR 论文深度总结

## 1. 核心问题与整体含义（研究动机与背景）

- **背景**：LLM 被广泛用作个性化写作助手，需要在延续未见过提示的同时保留作者特有的写作风格。联邦参数高效微调（PEFT）是自然的落地形式：客户端本地保留作者文本，只上传紧凑的适配器更新。
- **核心问题**：作者级数据天然是非独立同分布（non-IID）的——不同作者在词汇、句法、节奏、修辞结构和语域上都不同，而不只是样本分布不同。朴素的参数平均（FedAvg 式聚合）会把作者特有的修正方向与其他作者无关甚至相反的方向混合，使生成结果被拉向一个**共享语域**。
- **关键发现（失效模式定义）**：作者称之为 **author-style homogenization（作者风格同质化）**——续写在语义上依然流畅、合理，效用指标（如 BERTScore、MAUVE）保持可接受，但不同作者的生成结果在风格空间中**越来越难以区分**。这是一个"效用保持型"的失效，因此标准效用指标无法暴露它。
- **整体含义**：仅把原始文本留在本地并不足够；联邦聚合必须显式决定**哪些适配方向应当共享、哪些应当保持客户端私有**。论文据此提出可测量的评估协议与缓解方法 FAVoR。

## 2. 方法论

### 2.1 核心思想
- 采用**共享–私有适配器（shared–private adapter）**的非对称通信结构：
  - **共享适配器 A⁽ᵍ⁾**：唯一被上传与聚合的组件，承载可迁移的续写能力。
  - **私有残差包 ΔA⁽ᵖ⁾**：以 LoRA 因子级残差形式相对共享端点存储作者特有修正，**永不上传、永不聚合**。
- 贡献定位：共享–私有结构本身并非新架构，论文的新意在于把它定义为**作者风格残差**，用本地作者风格目标训练，并研究其在联邦续写中的同质化缓解作用。

### 2.2 关键技术细节

**（1）个性化模型与残差定义**
- 个性化模型：`p_i(y|x) = LM(y|x; θ ⊕ (A⁽ᵍ⁾_{i,τi} + ΔA⁽ᵖ⁾_{i,τi}))`，其中 θ 为冻结基座，⊕ 表示挂载适配器。
- 残差在 LoRA 因子上定义：`ΔU = U⁽ᵖ⁾ − U⁽ᵍ⁾`、`ΔV = V⁽ᵖ⁾ − V⁽ᵍ⁾`。
- 注意：论文明确**不假设有效权重可加性**（`ΔW(A⁽ᵍ⁾+ΔA⁽ᵖ⁾) ≠ ΔW(A⁽ᵍ⁾) + ΔW(ΔA⁽ᵖ⁾)`），交叉项在重建时保留在本地；这种分解只用于本地存储与重建，推理时能精确恢复本地训练出的秩 r 适配器。

**（2）ASCE（角度风格分类编码器）**
- 将文本映射为单位归一化风格嵌入：`z(x) = norm(E_φ(x))`。
- 训练使用 ArcFace 式角间隔目标：正作者角 `θ_a(x)=arccos(w_aᵀz(x))`，正 logit `s_a = γcos(θ_a + m_s)`，负 logit `s_k = γw_kᵀz(x)`；损失 `L_ASCE = −s_a + log Z_a`。
- 实际配置：distilroberta-base 骨干 → 768 维池化 → 线性投影到 256 维 → LayerNorm → ℓ2 归一化；γ=30.0，m_s=0.35 rad。
- **训练后丢弃分类头与原型，编码器冻结**，在 FL 中仅作本地风格度量模块。ASCE 训练作者与 FL 名单完全不相交。

**（3）本地作者目标**
- 每个客户端用本地参考集构造风格锚点：`q_i = norm(mean_{x∈D_ref_i} z(x))`，始终本地保存。

**（4）两阶段本地更新（每轮）**
- **共享阶段**：`L_shared = L_task + λ_prox‖A⁽ᵍ⁾_i − A⁽ᵍ⁾_t‖²`（向当前全局适配器做近端稳定），**不施加风格对齐信号**。
- **私有阶段**：
  - 用个性化模型对响应 token 做掩码加权池化得到风格状态 `h_i`；
  - 经轻量 2 层 MLP 投影头 P_ψ 得 `ẑ_i = norm(P_ψ(h_i))`；
  - 对齐损失 `L_align = 1 − cos(ẑ_i, q_i)`；
  - 总目标 `L_private = L_task + λ_align·κ_t·L_align`，λ_align=0.3，κ_t 在前 5% 私有步从 0 线性升到 1；
  - 梯度在共享端点 A⁽ᵍ⁾ 处被停止，只更新私有适配器；投影头每客户端每轮随机初始化、训练后丢弃，不上传、不用于推理。

**（5）联邦聚合**
- 客户端只上传共享增量 `ΔA⁽ᵍ⁾_{i,t} = A⁽ᵍ⁾_{i,t} − A⁽ᵍ⁾_t`；
- 服务器加权聚合 `ΔA⁽ᵍ⁾_t = Σ ω_i ΔA⁽ᵍ⁾_{i,t}`（主实验用均匀权重，因一客户端即一作者），再按 `A⁽ᵍ⁾_{t+1} = A⁽ᵍ⁾_t + η_g ΔA⁽ᵍ⁾_t` 更新。
- **数据本地性边界**：语料、参考集、作者目标、残差包、对齐隐状态均不上传。论文明确这只是"数据本地性"声明，**不是形式化隐私保证**。
