## 摘要
尽管大语言模型（LLMs）在各类基准测试中取得了显著成果，但它们与规范性价值观的对齐往往导致同质化回复，无法满足多样化的用户偏好。现有的免训练方法通常通过提示工程占用宝贵的上下文窗口，而基于训练的方法通常在训练后保持静态，无法支持真实场景所需的持续优化。为应对这些挑战，我们提出 COPE（Continual Optimization with Personalized embedding and self-Evaluation），一种面向稀疏用户反馈的真实交互场景的新型优化框架。我们的框架为每个用户分配可学习的个性化嵌入，并在单次更新步骤中协同整合偏好捕获、自评估校准和个性化回复优化。该方法的关键创新在于利用自评估生成代理奖励，从而在无法获得显式用户反馈时仍能实现模型的持续更新。实验表明，在稀疏反馈下，COPE 持续优于强免训练和基于训练的基线，并与检索增强提示（Retrieval-Augmented Prompting, RAP）保持互补。进一步分析证实了 COPE 可靠的自评估、有意义的偏好模式、稳定的通用能力，以及在偏好变化和替代评估器下的鲁棒性。

## Abstract
While Large Language Models (LLMs) have achieved remarkable results across various benchmarks, their alignment with normative values often results in homogenized responses that fail to address diverse user preferences. Existing training-free methods often occupy valuable context windows through prompt engineering, while training-based methods typically remain static post-training, failing to support the continual optimization required in real-world settings. To address these challenges, we propose COPE (Continual Optimization with Personalized embedding and self-Evaluation), a novel optimization framework tailored for real-world-motivated interaction settings with sparse user feedback. Our framework assigns learnable personalized embeddings to each user and synergistically integrates preference capture, self-evaluation calibration, and personalized response optimization within a single update step. A key innovation of our method is the use of self-evaluation to generate proxy rewards, enabling continuous model updates even when explicit user feedback is unavailable. Experiments show that COPE consistently outperforms strong training-free and training-based baselines under sparse feedback, and remains complementary to Retrieval-Augmented Prompting (RAP). Further analyses confirm COPE's reliable self-evaluation, meaningful preference patterns, stable general capabilities, and robustness under shifting preferences and alternative evaluators.

## 2. 方法论：核心思想与关键技术细节

### 2.1 核心思想

- 为每个用户 $u_i$ 分配**可学习个性化嵌入** $\mathbf{v}_i \in \mathbb{R}^{l \times d}$（$l$ 个虚拟 token，$d$ 为 token 嵌入维度），作为用户隐式偏好的紧凑表示。
- 在**单次统一更新步骤**中同时优化三个互补目标，并聚合梯度以避免顺序优化带来的离策略（off-policy）问题。
- 核心创新：用**自评估生成代理奖励（proxy reward）**，在无显式反馈时仍可持续更新模型。

### 2.2 三个优化目标

- **目标一：偏好捕获的监督微调（LSFT）**
  - 将个性化嵌入前置到文本嵌入序列，以查询 $q_i^t$、回复 $a_i^t$ 为条件，最大化生成用户文本反馈 $f_i^t$ 的似然。
  - 损失为逐 token 负对数似然（式 1）；**仅对 $\mathbf{v}_i$ 计算梯度，冻结模型参数 $\theta_t$**，强制偏好信息流入嵌入。

- **目标二：自评估校准的强化学习（Jeval）**
  - 让模型充当自评估器：先产生自我反思，再预测数值评分 $\hat{s}_i^t$；采用**教师强制策略**（概率 $q$ 引入真实文本反馈 $f_i^t$）校准评估逻辑。
  - 复合奖励（式 2–3）：$R_{\text{eval}} = r_{\text{bin}} + r_{\text{dist}}$，其中 $r_{\text{bin}}$ 为二值匹配奖励，$r_{\text{dist}} = (C_{\max} - |\hat{s}-s|)/C_{\max}$ 为归一化稠密距离奖励（因二值信号过稀疏而引入）。
  - 目标为最大化期望奖励并带 KL 惩罚（式 4）；**同时更新嵌入 $\mathbf{v}_i$ 与模型参数 $\theta_t$**。

- **目标三：个性化回复优化的强化学习（Jpolicy）**
  - 复合奖励由**完整性**与**个性化**相乘构成：$r_i^t = r_{i,\text{comp}}^t \cdot r_{i,\text{pers}}^t$（式 5–6）。
  - 完整性 $r_{\text{comp}} \in \{0,1\}$ 由额外评估器（Qwen-Flash）判定，仅关注任务完成度；个性化分在有反馈时用真实评分 $s_i^t$，无反馈时用代理评分 $\hat{s}_i^t$。
  - 乘积设计确保"完整性是个性化的前提"，避免为迎合风格而牺牲任务完成。
  - **仅更新模型参数 $\theta_t$，冻结嵌入 $\mathbf{v}_i$**，促使模型利用嵌入中的偏好表示。

### 2.3 算法流程（Algorithm 1）

- 初始化个性化嵌入 $\mathcal{V}^1$、两个独立 critic（$V_{\phi_{\text{eval}}}$、$V_{\phi_{\text{resp}}}$）。
- 每轮 session：
  1. 交互并收集数据：无反馈集 $\mathcal{D}_1^t$ 与有反馈集 $\mathcal{D}_2^t$。
  2. 计算 LSFT 梯度（仅 $\mathbf{v}$，用户 $\in \Omega_2^t$）。
  3. 计算 Jeval 梯度（$\theta$ 与 $\mathbf{v}$，PPO）。
  4. 计算 Jpolicy 梯度（仅 $\theta$，PPO）。
  5. **联合更新**：$\theta$ 聚合 $\nabla_\theta J_{\text{eval}} + \nabla_\theta J_{\text{policy}}$；$\mathbf{v}$ 聚合 $\nabla_\mathbf{v} L_{\text{SFT}} + \nabla_\mathbf{v} J_{\text{eval}}$。
- 采用 PPO（重要性采样、GAE、裁剪目标、KL 惩罚），两个 critic 从助手模型初始化并分别独立训练。
- 附录 D 给出**多轮会话扩展**：以完整对话轨迹 $h_i^t$ 替代单轮 tuple，使用会话级反馈，个性化嵌入在所有轮次共享。

  - 按领域字母顺序遍历，域内优先采样 MTS 任务。

## 6. 主要结论与发现

- **性能优势**：COPE 在三种反馈概率下均优于强免训练（PAP、SR/DR/Q-DR）与训练基线（T-PAP）；$p=0.75$ 时达 4.74，PAP 仅 3.69；COPE+SR 在所有设置下最优（峰值 5.36）。
- **与检索增强互补**：COPE+SR 比 T-PAP+SR 高 0.32–0.40；SR 对 COPE 的提升（0.50–0.62）大于对 T-PAP 的提升（0.29–0.36），说明紧凑隐式偏好与显式检索历史互补。
- **自评估可靠**：总体 Pearson 相关 $r=0.81$（训练期）/ $r=0.71$（留出），实例级配对方向一致率 72.63%。
- **嵌入具语义结构**：聚类显示嵌入按偏好模式（超越粗粒度人口统计）组织用户，如高收入商务旅行者分为现代审美与传统品味两簇。
- **通用能力稳定**：优化后 IFEval、GSM8K 略有提升，MMLU 从 60.12 微降至 59.93，均在标准差内，未见灾难性遗忘。
- **偏好漂移鲁棒**：域内漂移后快速恢复并继续提升；跨新领域漂移虽有即时下降，但随训练持续上升。
- **跨模型与跨评估器鲁棒**：Qwen3 系列内随规模单调提升（4.69→5.49），Llama-3.1-8B 亦有效；DeepSeek-V3 作为用户模型时排序保持；人工盲测支持 COPE。

  - 创新性地用**自评估生成代理奖励**解决稀疏反馈难题，最大化利用所有交互数据。
  - 个性化嵌入为**紧凑用户参数**（每用户仅约 $1.2\times10^{-5}$ 总参数量），高效可扩展。
  - 完整性×个性化的乘积奖励设计，防止以牺牲任务完成换取风格偏好。
  - 明确区分各目标下可训练参数（冻结/更新 $\mathbf{v}$ 或 $\theta$），避免过拟合与能力破坏。
- **实验亮点**：
  - 时序遍历协议将静态基准转化为可控的持续优化评估，保证偏好先暴露、任务后测试。
  - 消融设计细致（目标组合、参数配置、嵌入长度）。
  - 鲁棒性验证全面：跨家族评估器、人工盲测、偏好漂移、模型规模扩展。
