## 摘要
生成式推荐（GR）已成为序列推荐的一种新范式，其中代表性的工作通过残差量化将物品编码为分层语义ID，并逐词预测这些ID。然而，这种生成式公式在推荐任务方面仍存在结构鸿沟：将多词元ID展平为单一序列会破坏物品级别的结构，而分层码本上训练与推理之间的不一致则导致语义漂移。为弥补这两个鸿沟，我们提出BARGE，它采用物品上下文感知注意力（ICA）在编码过程中恢复物品级别的结构，并利用分层路径重排序（HPR）结合双路径解码（DPD）在解码过程中从两个互补角度抑制语义漂移。在公共基准和大规模离线测试上的大量实验与分析研究表明，BARGE实现了卓越的推荐性能。在腾讯平台上的在线A/B测试显示，点击率提升0.60%，独立点击访客数提升1.34%，总阅读时间提升1.70%，证实了BARGE在工业级推荐中的实际价值。

## Abstract
Generative Recommendation (GR) has emerged as a new paradigm for sequential recommendation, in which a representative line of work encodes items into hierarchical semantic IDs via residual quantization and predicts the IDs token by token. However, this generative formulation still exhibits structural gaps with respect to the recommendation task: flattening multi-token IDs into a single sequence destroys item-level structure, and the inconsistency between training and inference over a hierarchical codebook gives rise to semantic drift. To bridge these two gaps, we propose BARGE, which employs Item Context-Aware Attention (ICA) to restore item-level structure during encoding, and Hierarchical Path Reranking (HPR) together with Dual-Path Decoding (DPD) to suppress semantic drift from two complementary angles during decoding. Extensive experiments and analytical studies on public benchmarks and a large-scale offline test demonstrate that BARGE achieves superior recommendation performance. An online A/B test on a Tencent platform yields improvements of 0.60% in click-through rate, 1.34% in click unique visitors, and 1.70% in total reading time, confirming the practical value of BARGE in industrial-scale recommendation.

# 论文总结：Bridging the Structural Gap: Adapting Autoregressive Generation for Recommendation

## 1. 核心问题与整体含义（研究动机和背景）

- **核心问题**：现有生成式推荐（Generative Recommendation, GR）方法将物品通过残差量化编码为多层级的语义ID（如 RQ-VAE），并将用户历史交互序列展平为 token 序列输入自回归模型。这种做法导致两个结构性缺陷：
  - **物品边界丢失（P1）**：展平操作消除了序列中物品之间的边界，自注意力机制将所有 token 同等对待，无法区分同物品内 token 与不同物品的 token，严重破坏了物品级别的结构信息。
  - **语义漂移（P2）**：层级语义ID构成树形码本，解码时若某一层选择了错误的前缀，后续所有层都将被导向错误的子树，标准束搜索仅根据局部概率选择，无法感知这种累积性偏差，导致深层准确率急剧下降（如 TIGER 在 c3 层当前缀错误时准确率从 77% 降至 0.6%）。
- **研究意义**：弥合上述结构性鸿沟，使生成式推荐在保持对数级推理复杂度优势的同时，达到更优的推荐精度，并在工业规模系统中验证其实际价值。

## 2. 方法论

### 核心思想
- 提出 **BARGE** 模型，从编码和解码两端分别修复两个间隙。编码侧引入物品上下文感知注意力（ICA）恢复物品结构；解码侧从两个互补角度抑制语义漂移：内部路径重排序（HPR）和跨通道双路径解码（DPD）。

### 关键技术细节

#### （1）物品上下文感知注意力（ICA）
- **动机**：在编码之前，为每个 token 补充其所属物品的整体上下文。
- **实现**：
  - **交叉注意力池化**：用一个可学习查询向量 `q` 对同一物品的 L 个 token 嵌入进行交叉注意力，得到物品级表示 `z`。
  - **上下文投影**：用 MLP 将 `z` 非线性变换为 `ẑ`。
  - **门控残差融合**：对每个 token 计算门控向量 `g`（由 token 特征与 `ẑ` 拼接后经 sigmoid 得到），然后 `x̂ = x + g ⊙ ẑ`。门控值控制在 0.35–0.38 左右，表明模型学习到适度的融合强度，不会覆盖原有 token 信息。

#### （2）层次路径重排序（HPR）
- **动机**：标准束搜索在逐层解码时仅依赖局部 token 概率，易因低层错误导致路径偏移。HPR 在每层引入全局路径级语义评分以纠正错误。
- **实现**：
  - **累积路径嵌入**：对每条部分路径，将其所有已选 token 的嵌入求和，得到 `p(l)`。
  - **双塔评分器**：每层维护两个投影网络（上下文塔和路径塔），将解码器初始隐藏状态 `h0` 与路径嵌入 `p(l)` 映射到共享低维空间，计算余弦相似度（经可学习温度缩放）。
  - **训练**：通过对称 InfoNCE 损失（`L_HPR`）训练，正样本为当前样本的 `h0` 与真实路径嵌入，负样本包括 batch 内负样本和前缀感知负样本（高概率但错误的前缀）。
  - **推理**：在每层束扩展后，先保留由生成概率排序的 Top-N 候选（N > B），再用 HPR 评分与生成概率加权融合（加权系数 λ），重新选出 Top-B 路径继续下一层。

#### （3）双路径解码（DPD）
- **动机**：单一编码量化通道可能丢失物品的某些语义侧面，导致该侧面下的正确叶子节点永远不可达。DPD 通过正交分解将物品表示分裂到两个互补通道，任一通道命中即可恢复。
- **实现**：
  - **OSQ-VAE 分词器**：将预训练物品嵌入 `z` 乘以一个可学习的正交旋转矩阵 `R`（由 Householder 反射参数化，保证正交性），然后将旋转后的特征 `z̃` 对半切分为 `z̃_A` 和 `z̃_B`，分别用独立的残差量化栈得到两套语义ID `s_A` 和 `s_B`。旋转矩阵使得两个子空间正交且互补。
  - **双解码器**：共享编码器，两个独立解码器分别针对 `s_A` 和 `s_B` 进行自回归预测，各自配备自己的 HPR 评分器。
  - **推理融合**：每个解码器独立进行束搜索，得到两个候选列表后，对每个物品取两通道得分的 LogSumExp 作为最终得分（OR 语义），然后截断 Top-K 并计算指标。

## 8. 不足与局限

- **依赖语义 ID 质量**：BARGE 的性能建立在 OSQ-VAE 或 RQ-VAE 能够产生高质量层次语义 ID 的前提上。若物品嵌入质量差或码本大小不合适，可能削弱方法效果。
- **两阶段训练**：先预训练 OSQ-VAE，再训练推荐模型，无法端到端联合优化，可能存在子优。
- **超参数敏感**：HPR 的 λ 和 Top-N 需在验证集上调优，虽然区间稳定但仍需调试。
- **实验未覆盖更多领域**：只测试了 Amazon 两个类别和腾讯一个平台，对新闻、视频、社交等其他推荐场景的泛化性尚需验证。
- **未与更近期 GR 方法对比**（如 TrieRec、PROMISE、Reg4Rec 等）：论文虽提及但未在相同设置下比较，可能存在对比不完全。
- **计算资源未详细报告总训练时间**：只给出每 epoch 时间，未说明总时长和收敛轮数。
