## 摘要
用户表示是工业推荐系统中高影响力的建模问题之一：用户编码方式的单一进步就能在平台规模上传播到检索、排序和完整性任务中。以往的工业用户表示工作要么构建一个输出一个或多个嵌入向量的单一用户模型，要么构建一个带有任务特定适配的共享主干网络。在本文中，我们提出了 Mosaic，一个基础用户建模平台，它利用一组专家来学习用户嵌入。该集群包括四种架构多样的模型家族——记忆驱动型、密集重型、序列基础型和 CoTrain 模型——每个模型专注于用户行为的不同方面。我们开发了 MRM（多任务关系挖掘）和 CRL（余弦冗余损失）技术，以最大化每个新专家的边际信息贡献。我们还引入了 CoEval 和 User Tower Zero-Out，这是一种新的无需日志记录的嵌入评估框架，可在保持下游对齐精度的同时提高开发速度。我们的混合 CPU/GPU、在线和离线服务栈允许每个专家选择适当的服务策略以满足新鲜度、延迟和计算要求。Mosaic 除了在线收益外，还提供了一致且显著的离线 NE 改进。

## Abstract
User representation is one of the highest-leverage modeling problems in industrial recommendation systems: a single advancement in how users are encoded can propagate across retrieval, ranking, and integrity tasks at platform scale. Prior industrial user representation work builds either a single user model that emits one or more embedding vectors or a shared backbone with task-specific adaptation. In this paper, we present Mosaic, a foundational user modeling platform that employs a fleet of specialists to learn user embeddings. The fleet comprises four architecturally diverse model families - memorization-driven, dense-heavy, sequential-based, and CoTrain models - each focusing on a distinct facet of user behavior. We developed MRM (Multi-task Relations Mining) and CRL (Cosine Redundancy Loss) techniques to maximize the marginal information contribution of each new specialist. We also introduce CoEval and User Tower Zero-Out, new logging-free embedding evaluation framework that improves development velocity while preserving downstream-aligned accuracy. Our hybrid CPU/GPU, online-and-offline serving stack allows each specialist to choose the adequate serving strategy to meet the freshness, latency, and computational requirements. Mosaic delivers consistent and significant offline NE improvements in addition to online gains.

## 2. 方法论  
### 核心思想  
- **集群设计**：包含四个架构不同的专家家族：  
  - **Memorization-driven**：利用大规模哈希表捕捉细粒度偏好（如喜欢的运动）。  
  - **Dense-heavy**：对聚合计数器特征进行非线性交互（如30天平均点赞数）。  
  - **Sequential-based**：基于 HSTU 和 MoE 路由建模用户行为序列（如：MMA → Wrestling → Jiu-jitsu）。  
  - **CoTrain**：结合下游排序器的梯度进行端到端训练，使嵌入与目标场景对齐。  
- **训练流程**：每个专家包含一个**训练专用架构**（含多任务监督头）和一个**用户塔**。训练后只部署用户塔进行推理，大幅降低服务开销。  

### 关键技术细节  
- **最大化独特知识**：  
  - **MRM（Multi-task Relations Mining）**：通过 Spearman 秩相关分析任务间关系，构造复合标签（如“点赞+评论”四类），监督联合分布，挖掘单任务无法捕捉的细粒度意图。  
  - **CRL（Cosine Redundancy Loss）**：最小化新嵌入与已有嵌入之间的余弦相似度，鼓励表示正交化，增加增量信息。总损失为 \( \mathcal{L} = \mathcal{L}_{\text{main}} + \lambda \mathcal{L}_{\text{red}} \)，且采用预热调度。  
  - **其他策略**：特征任务对齐（基于 FI 选择输入特征）、先验嵌入条件化（将已有 Mosaic 嵌入作为输入）。  

- **无日志评估框架**：  
  - **CoEval**：冻结用户塔，将其嵌入直接输入下游排序器副本，快速计算 NE 增量，无需部署和日志积累，迭代速度提升 3–5×。  
  - **User Tower Zero-Out**：在上游模型中清零用户塔输出，衡量其边际贡献。  

- **混合服务栈**：  
  - 支持 **CPU 在线推理**、**GPU 在线推理**、**GPU 离线推理**三种路径，按每个专家的新鲜度、延迟和计算需求选择。  
  - GPU 在线优化包括 AOTI 编译、模型拆分、memcache 缓存，累计减少 GPU 服务资源 79%，同时改善延迟。

### 算法流程（文字说明）  
1. 对每个专家，使用其特定的训练架构和用户塔，通过 MRM 构造复合标签、CRL 正则化进行多任务训练。  
2. 训练完成后，仅导出用户塔参数，通过三种服务路径之一生成用户嵌入。  
3. 下游排序器将这些嵌入作为标准特征输入，用于预测。  
4. 新专家上线前，通过 CoEval 快速评估；正式部署后通过在线 A/B 验证。
