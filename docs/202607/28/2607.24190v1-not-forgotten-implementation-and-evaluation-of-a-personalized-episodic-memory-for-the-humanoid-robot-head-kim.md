## 摘要
依赖大型语言模型进行对话的社交机器人无法跨会话保留信息。这种记忆缺失违反了社交期望，可能阻碍持久关系的形成。本文提出一种轻量级情景记忆模块，该模块将基于向量的语义检索与大语言模型控制的对话系统相结合，并部署于人形机器人头部Kim上。该模块采用混合评分函数，将余弦相似度与记忆强度指标相结合，以检索上下文相关的过往交互，并将其注入生成提示中。通过采用人机交互评估量表（HRIES），该系统的评估基于一项被试内设计的视频在线研究（N = 43）。结果表明，情景记忆显著提升了用户感知的社交性（d = 0.60, p < .001），其中对感知可信度（d = 0.62）和温暖度（d = 0.56）的影响最强。感知干扰度保持不变（d = 0.00），表明所实现的个性化回忆方法未引发隐私相关不适或恐怖谷效应。这些发现表明，情景记忆在具身人机交互中充当社交润滑剂，提升关系质量而不引发负面情感反应。

## Abstract
Social robots that rely on large language models for conversation are unable to retain information across sessions. This absence of memory violates social expectations, potentially preventing the formation of persistent relationships. This paper presents a lightweight episodic memory module that integrates vector-based semantic retrieval with an LLM-controlled dialog system, deployed on the humanoid robot head Kim. The module employs a hybrid scoring function combining cosine similarity with a memory strength metric to retrieve contextually relevant past interactions and inject them into the generation prompt. The system was evaluated in a within-subjects video-based online study (N = 43) using the Human-Robot Interaction Evaluation Scale (HRIES). Results show that episodic memory significantly increased perceived sociability (d = 0.60, p < .001), with the strongest effects on perceived trustworthiness (d = 0.62) and warmth (d = 0.56). Perceived disturbance remained unchanged (d = 0.00), indicating that the implemented approach to personalized recall did not trigger privacy-related discomfort or uncanny valley effects. These findings suggest that episodic memory serves as a social lubricant in embodied Human-Robot Interaction, enhancing relational quality without eliciting negative affective responses.

## 2. 方法论：核心思想、关键技术细节、公式/算法流程

### 核心思想
- 将**基于向量的语义检索**与**LLM控制的对话系统**相结合，在LLM生成回复前，从向量数据库中检索与当前用户相关的历史交互记忆，并将其注入生成提示（prompt）中，从而实现个性化回忆。
- 检索策略采用**混合评分函数**：在余弦相似度基础上，引入**记忆强度**指标（融合时间衰减、访问频率、情感强度），优先返回语义相关且重要的记忆。

### 关键技术细节

**（1）系统架构**
- 采用微服务化设计，所有组件容器化（Docker），通过HTTP REST API和WebSocket通信。
- 机器人Kim配备14个气动执行器（头动、表情控制）；语音识别（Whisper）、语音合成（XTTS）、唇同步、人脸追踪均作为独立服务运行于Nvidia Jetson Orin AGX上。
- 交互流水线：用户语音 → ASR转录 → 记忆模块检索上下文 → LLM生成回复 → TTS合成+同步唇动。

**（2）情景记忆模块**
- 实现为FastAPI微服务，提供三个REST端点：`POST /memory`（存储新交互）、`POST /memory/query`（检索）、`POST /memory/consolidate-all`（记忆合并）。
- LLM采用`gpt-4.1-nano`，系统提示定义其角色为“讽刺、友好的安卓机器人头Kim”。

**（3）向量化与存储**
- 每轮对话文本片段经OpenAI Embeddings API（`text-embedding-3-small`）转为1536维向量，存储于本地Qdrant数据库。
- 每条记忆附带基于Russell圆周模型的情感元数据（效价v和唤醒度a），通过LLM情感分类获取。情感强度定义为 `I = sqrt(v^2 + a^2)`。

**（4）Hybrid Retrieval Scoring（混合检索评分）**
- 第一阶段：使用余弦相似度从Qdrant中过度获取3倍候选（例如需要k条，则取3k个候选）。
- 第二阶段：使用混合评分函数重新排序候选记忆：
  `R(m) = α · sim(m) + S(m)`
  - `sim(m) ∈ [0, 1]` 为余弦相似度
  - `α = 50` 为启发式调节因子
  - `S(m)` 为记忆强度分数。

- 记忆强度分数完整公式（公式5）：
  ```
  S(m) = max(0, 
    [3.0 * max(0, 1 - 0.1 * Δt_creation)
     + 2.0 * ln(1 + N_access)
     + 1.5 * max(0, 1 - 0.05 * Δt_last_access)]
    * [1 + 0.5 * sqrt(v^2 + a^2)]
  )
  ```
  - `Δt_creation` 和 `Δt_last_access` 以天为单位，`N_access` 为访问次数。
  - 内层max函数将时间衰减、最近访问衰减的负值剪为0。
  - 情感强度作为乘性增强因子：情感越强，记忆越难衰减。

- 重排序后，取前k条记忆注入LLM系统提示，同时强制要求“自然使用记忆”、“不一次性强制所有信息”，将上下文定位为可选的背景知识。

**（5）延迟控制**
- 检索的嵌入耗时约0.32秒，搜索/重排序约0.36秒；控制器对检索同步阻塞，记忆写入异步后台线程进行。

**（6）实验条件切换**
- 基线条件：停止记忆容器的运行，导致检索请求超时（5秒），LLM仅根据当前会话轮次生成回复（记忆提示被省略）。
- 记忆增强条件：记忆模块活跃，从预填入的用户个人偏好（第一次问卷收集）的Qdrant数据库中检索。

## 6. 主要结论与发现

1. **社交性显著提升**（H1支持）：
   - 记忆增强条件 vs 基线在HRIES社交性子量表上表现出**中度至大效果量**：`t(42) = -4.15, p < .001, d = 0.60`。
   - 项目层面：**可信度**（d=0.62）和**温暖感**（d=0.56）提升最显著；**可爱感**（d=0.33）显著但效果较弱；**友好感**无显著变化（存在天花板效应，基线均值已达5.00/7）。
   - 含义：基本礼貌（友好）无需记忆即可实现；记忆添加的是“被了解”的深度关系感（可信和温暖）。

2. **干扰度无变化**（H4不受支持也不被拒绝，实际为无差异）：
   - 基线均值4.22 vs 记忆增强均值4.23，`t(42) = -0.05, p = .960, d = 0.00`。四个组成条目（creepy, scary, uncanny, weird）均无显著差异。
   - 表明所实现的个性化回忆未引发隐私不适或恐怖谷效应。作者归因于：混合评分保证了语义相关性，避免了无关记忆；提示设计将记忆定位为可选背景知识。

3. **能动性（Agency）和有生命性（Animacy）无显著变化**：
   - 能动性：`d = 0.11`；有生命性：`d = 0.17`（不显著）。可能因为视频基格式限制了能动性判断，或记忆注入采用了“非显式”方式，未展示机器人主动推理能力。

4. **全局偏好**：63%参与者选择记忆增强系统，37%选择基线，但卡方检验未达显著（`p = .093`）。表明社交性提升并未自动转化为明确的整体偏好。

5. **结论**：情景记忆在具身人机交互中可作为“社交润滑剂”，提升感知关系质量（尤其是信任与温暖），而不触发负面情感反应。
