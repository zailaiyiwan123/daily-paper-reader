## 摘要
大型语言模型越来越多地通过奖励建模与人类偏好对齐，但用户偏好数据是敏感的，通常无法集中存储。联邦学习在学习共享初始奖励模型的同时将这些数据保留在本地，随后通过本地微调为每个客户端进行个性化。由于用户经常对同一对响应分配相反的标签，现有的联邦方法通过将相似客户端聚类并为每个组训练一个奖励模型来解决偏好异质性，假设每个组需要自己的初始化。我们表明这一假设是不必要的。在均衡的偏好组下，单个FedAvg模型尽管从近乎随机的准确率开始，在仅进行几步本地优化后就能超越为每个真实组单独训练的奖励模型。我们将这一现象归因于共享初始化的平坦性：对所有客户端进行平均学习到更丰富的共享表示，这些表示能够区分响应，同时抵消冲突的偏好方向，使模型接近一个可以快速适应的决策边界。组不平衡破坏了这种效应，因为抵消变得不对称，使少数派客户端离边界太远而无法恢复。受此观察的启发，我们提出了FedGD（组去偏联邦学习），它在联邦训练期间发现潜在偏好组，并使用组去偏客户端采样学习单个奖励模型。通过抵消组不平衡的影响，FedGD学到的初始化保持高度适应性，无需事先了解底层组即可实现有效的个性化。

## Abstract
Large language models are increasingly aligned to human preferences via reward modeling, but user preference data are sensitive and often cannot be centralized. Federated learning keeps such data local while learning a shared initial reward model, which is later personalized for each client through local fine-tuning. Because users often assign opposite labels to the same pair of responses, existing federated methods address preference heterogeneity by clustering similar clients and training one reward model per group, assuming that each group requires its own initialization. We show that this assumption is unnecessary. Under balanced preference groups, a single FedAvg model, despite starting at nearly random accuracy, surpasses reward models trained separately for each ground-truth group after only a few local optimization steps. We attribute this phenomenon to the flatness of the shared initialization: averaging across all clients learns richer shared representations that distinguish responses while canceling conflicting preference directions, leaving the model near a decision boundary that can be rapidly adapted. Group imbalance breaks this effect as the cancellation becomes asymmetric and leaves minority clients too far from the boundary to recover. Motivated by this observation, we propose FedGD (Federated Learning with Group Debiasing), which discovers latent preference groups during federated training and learns a single reward model using group-debiased client sampling. By counteracting the effect of group imbalance, FedGD learns an initialization that remains highly adaptable, enabling effective personalization without prior knowledge of the underlying groups.

## 一、核心问题与整体含义（研究动机与背景）

- **研究背景**：LLM 对齐通常依赖奖励模型来预测人类偏好，再通过 RLHF 等方法优化语言模型。然而，用户偏好数据高度敏感，常因隐私法规（如 GDPR、CCPA）和跨司法管辖区限制而无法集中存储。联邦学习提供了一种替代方案：数据保留在本地，服务器只聚合模型更新。
- **核心问题**：在**偏好异质性**下（不同用户可能对同一对响应给出相反偏好标签），什么是一个好的个性化初始化模型？现有方法（如 FedBiscuit、FedLEASE、IFCA 等）广泛采用"聚类客户端 + 每组训练一个模型"的策略，其隐含假设是：**客户端更适合从一个从未对冲突目标做平均的模型开始**。本文直接挑战这一前提。
- **关键发现**：在平衡偏好组下，单一的 FedAvg 全局模型尽管适配前精度接近随机猜测，但经过**少量本地梯度步骤**即可超越分别针对每个真实偏好组独立训练的模型（Multi-CL）。作者将这一现象归因于共享初始化的**平坦性**：FedAvg 聚合保留了所有客户端共识的"区分特征表示"，同时抵消了冲突的"偏好方向选择"，使模型停留在决策边界附近的平坦区域，能够被快速局部适应。
- **不足与修正**：当偏好组规模不平衡时，这种抵消变得不对称，模型偏向多数派偏好，少数派客户端离决策边界过远而难以在少量步骤内恢复。为此提出 **FedGD**：在不事先知晓底层组结构的情况下，通过联邦训练发现潜在偏好组并执行组去偏采样，恢复高质量初始化。

## 二、方法论

### 2.1 核心思想

将偏好学习分解为两个正交组件：
- **共享知识**：识别区分两个响应的潜在特征（所有客户端一致）。
- **客户端特定知识**：在潜在特征上偏好哪一侧（不同客户端不一致）。

联邦学习的目标不是直接产出最终个性化模型，而是学习一个**捕获共享知识且易于快速局部适应**的初始化。

### 2.2 诊断指标

- **Gradient Quotient（GQ）**：度量初始化模型的平坦性（梯度在单步更新后的变化率）。GQ 越小说明局部优化越稳定，连续本地步骤能相互增强。按 LoRA 层分组：Body（前 16 层）和 Head（后 8 层）。
- **Headroom（H）**：单样本"一步可纠正性"，衡量一次全批量训练步骤对保留集（R，初始正确样本）和纠正集（W，初始错误样本）边际值的影响。

### 2.3 FedGD 算法流程（三阶段）

**Phase 1：偏好组发现（前 R/2 轮）**
- 服务器维护 K 个专家模型 {θ_k} 和一个参考模型 θ_g。
- 每 T 轮基于验证损失对客户端重新分配专家（硬聚类）。
- 服务器采用**组去偏采样**（每组被采样的概率与其基数成反比，使参与集均匀覆盖各组），并令专家在组内累积平均后做移动平均更新。
- 参考模型 θ_g 对所有参与客户端做统一平均，作为重分配的"中性起点"。
- 结束时冻结分组 {A★_k}，丢弃空簇。

**Phase 2：奖励模型训练（后 R/2 轮）**
- 从随机初始化出发，训练单一奖励模型 φ。
- 仍使用组去偏采样；**层次化聚合**：组内按数据量加权，组间统一平均，保证去偏效果在聚合层不被破坏。

**Phase 3：最终个性化**
- 服务器广播 φ^R 给所有客户端，每个客户端在本地数据上微调少量步骤，得到个性化模型 FedGD-FT。

### 2.4 与 FL_target 的关系

当发现的分组与真实偏好组一致时，FedGD 退化为本文实验中的 FL_target（理想上限参考）。实验表明 FedGD 无需精确恢复真实分组，只需足以消除采样偏差即可。

## 六、主要结论与发现

1. **分组独立初始化并非最优**：平衡偏好组下，单一 FedAvg 模型经过 10 步本地微调即可达到 93.45%，超过 Multi-CL（91.45%）和 CL（52.15%）。
2. **机制归因**：FedAvg 的初始化具有显著更低的 GQ（平坦损失），接近决策边界（margin ≈ ±2.4），使连续本地步骤保持对齐。CL 和 Multi-CL 均陷入饱和区（margin ≥ +16）。
3. **组不平衡导致失败**：当偏好组规模失衡（15/15/5/5），FL 的 GQ_B 从 0.11 升至 0.88，少数派客户端 margin 深达 -27，10 步内仅纠正 2.09% 的错误样本。
4. **组去偏采样恢复能力**：仅改变客户端采样策略（FL_target），acc₁₀ 从 61.75% 恢复至 92.35%，且各组均快速收敛。
5. **无需精确分组**：K=2/3/4 时 FedGD 的 acc₁₀ 稳定在 91.0%-92.8%，说明只需去除采样偏差即足够。
6. **FedGD 的普适性**：在 Qwen-1.5B 和 Gemma-2B 上均取得最优个性化精度；对 K 的选择不敏感。
7. **多全局模型可能有害**：FedBiscuit 和 Soft-FL 在真实数据上甚至出现个性化退化（精度下降），不如单一模型 CL。

## 七、优点

- **反直觉的重要发现**：系统地否定了"冲突必须分组消除"的直觉，揭示了共享初始化平坦性对个性化效率的决定性作用，为联邦偏好对齐提供了新视角。
- **定义清晰的可诊断指标**：GQ 和 Headroom 能分别量化初始化"是否平坦"和"是否朝向正确方向"，具备可解释性和可推广性。

- **通过分层聚合实现双重去偏**：组内按数据量加权 + 组间统一平均，兼顾组内异质与组间均衡。
