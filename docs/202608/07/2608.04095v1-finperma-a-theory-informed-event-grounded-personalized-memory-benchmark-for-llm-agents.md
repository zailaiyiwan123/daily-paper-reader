## 摘要
大语言模型（LLM）智能体越来越多地被用作金融咨询等高风险领域的个性化助手，但仍不清楚它们是否能在长时间跨度内维护和更新个体化用户模型。现有的个性化记忆基准主要测试事实保留或依赖约束较弱的模型生成轨迹，对事件驱动的偏好适应探索不足。我们提出FinPerMA，一个事件锚定的基准，针对冻结的纵向投资者轨迹评估个性化记忆。其生成流程结合了确定性、理论驱动的冲击规则，受控LLM叙述和自动质量筛选；一个“冲击后”检查点隔离智能体是否已将重要事件纳入其持久用户模型。在来自276个角色的2,994个问题上，七个前沿LLM和最多七种记忆配置远未饱和：没有全上下文配置超过约0.47的总体准确率或约39%的多项选择准确率。归因分析表明，基于摘要的记忆通常保留事实细节而丢失个性化所需的偏好信号；因此简单的检索可以胜过专门构建的记忆系统，且差距在冲击后扩大。

## Abstract
Large language model (LLM) agents are increasingly used as personalized assistants in high-stakes domains such as financial advising, yet it remains unclear whether they can maintain and update an individualized user model over long horizons. Existing personalized-memory benchmarks primarily test factual retention or rely on weakly constrained model-generated trajectories, leaving event-driven preference adaptation underexplored. We introduce FinPerMA, an event-grounded benchmark that evaluates personalized memory against frozen longitudinal investor trajectories. Its generation pipeline combines deterministic, theory-informed impact rules, controlled LLM narration, and automated quality screening; a Post-Shock checkpoint isolates whether an agent has integrated a material event into its persistent user model. On 2,994 questions from 276 personas, seven frontier LLMs and up to seven memory configurations remain far from saturated: no full-context configuration exceeds approximately 0.47 overall accuracy or approximately 39% on multiple-choice questions. Attribution analysis shows that summary-based memory often preserves factual details while losing the preference signals needed for personalization; simple retrieval can therefore outperform purpose-built memory systems, with the gap widening after shocks.

## 2. 方法论：核心思想、技术细节、公式与流程

### 2.1 核心思想
- 构建一个冻结的纵向投资者轨迹语料库，每条轨迹包含：人物画像（Persona）、事件时间线（5–8 个真实金融/生活事件）、多轮多会话对话、以及标注好的评测问题。
- 用**确定性理论规则**约束用户偏好的事后变化，再用**受控 LLM 叙述**生成自然语言反应，最后经**自动校验**确保标签可审计，从而保证轨迹的一致性与可复现性。
- 设置 **Post-Shock 检查点**，在重大冲击事件后立即考察智能体是否已将事件纳入持久用户模型。

### 2.2 技术细节与流程

#### 阶段 1：人物合成（Persona Synthesis）
- 基于公开投资者调查数据采样人口统计、财务特征（年龄、教育、收入、经验等）及心理测量变量（Big-Five 人格、10 项风险容忍度得分、5 项金融素养测验）。
- 依据 Pompian (2012) 的规则映射将人物划分为四种行为投资者类型（BIT）：Passive Preserver (PP)、Friendly Follower (FF)、Independent Individualist (II)、Active Accumulator (AA)，并通过拒绝抽样保证各类别占比 ≥20%。

#### 阶段 2：事件时间线构建
- 整理 97 个带日期的真实事件（17 宏观、64 行业、16 个人），覆盖 2020–2026，例如 2020 年 COVID 崩盘、2022 年加息周期、2023 年 SVB 倒闭。
- 每个事件记录类型、日期、受影响资产/领域、区域、摘要、典型反应、严重度（1–5 分制）。每个角色采样 5–8 个事件，要求类别多样且事件间隔 ≥4 周。

#### 阶段 3：影响模型（Impact Model）
三层架构（图 2），输入 (persona P, event E, memory bank M)，输出事件反应 R：

- **Layer 1：规则驱动的 ImpactConstraint（确定性）**
  由五个子模块聚合生成一个包含方向、幅度范围、偏差集合、经验 μ̂、记忆锚点的约束对象：

  - **M1 BIT 分类**：决定后续方向的倾向与禁用偏差。
  - **M2 事件冲击系数**：查表映射 `(BIT, event_type) → direction, coefficient`，基础幅度公式：
    
    基础幅度 = c[E.type] × (E.severity / 5)
  
  - **M3 Big-Five 乘数**：神经质（N）与外向性（E）调节幅度：
    
    m_trait(P) = 1 + 0.30(P.N − 0.5) − 0.15(P.E − 0.5)
  
  - **M4 经验历史聚合**：基于加权历史收益的年龄依赖权重：
    
    μ̂ = Σ_i w_i r_i，其中 w_i = a_i^λ / Σ_j a_j^λ，a_i = max(1, t − y_i + 1)，λ=1.3
  
    随后用 clip(1 − 0.2μ̂, 0.6, 1.4) 调制冲击幅度。
  
  - **M5 记忆参考锚**：基于符号记忆激活，记忆有效时计算加权参考值：
    
    激活条件 s(m,x) = min(1, 0.8·J(T_m,T_x) + 0.2·I[e_m=e_x]) ≥ 0.3；记忆强度 h_m = exp(−0.1 years_m) × (1 + rehearsal_m)。
  
  - 聚合输出 `ImpactConstraint`：包含 `direction`（risk_on/risk_off/neutral）、`magnitude_range`、`biases_likely`、`biases_forbidden`、`experience_mu_hat`、`memory_anchor`。该对象对固定输入完全确定。

- **Layer 2：受控 LLM 叙述器（约束生成）**
  - 将 ImpactConstraint 作为硬约束并入 prompt，强制生成 JSON 格式事件反应，字段包括：
    - `preference_deltas`（(field, delta, new_value) 元组列表）
    - `inner_monologue`（需引用至少一个 memory_anchor 项）
    - `biases_triggered`（限于允许集合内）
    - `confidence`（[0,1] 标量）
  - 约束按“MUST satisfy”处理而非软引导。

- **Layer 3：自动校验器 + 重试**
  - 硬检查项：风险方向一致性、风险增量范围（20% 容差）、禁止偏差排除、冲击事件演化类型一致性。
  - 经验 μ̂ 与记忆锚条件作为软诊断（不拒绝候选）。
  - 失败则反馈重试，最多 3 次；全部失败输出模板回退（confidence=0.2，layer3_fallback=True）。
  - 伪代码（Algorithm 1）：ComputeConstraint → 循环 LLMNarrator → Validate → 通过则返回，否则并入失败反馈再试。

#### 阶段 4：对话合成
- Task-Oriented User Simulator 以 (P, E, R) 为私有状态，生成多会话“投资者-顾问”对话，偏好通过交易、提问和担忧隐含呈现。
- 质量控制：确定性去重、隐含性过滤、金融合理性过滤，加上多 LLM 投票，只有通过的会话进入冻结的 v8gold 语料。

#### 阶段 5：问题生成
- **三维评估框架**：
  - Memory Fidelity (MF)：对人物事实属性与历史行为的回忆。
  - Preference Reasoning (PR)：从行为轨迹推断隐含偏好。
  - Context Adaptation (CA)：在全新决策场景中应用（可能已更新的）偏好。
- **四个时间检查点**：
  - Zero-memory（控制组，仅测参数知识下限）
  - In-timeline（事件推进中的持续记忆）
  - Post-distraction（无关会话后的记忆保留）
  - **Post-Shock（新颖点，重大冲击后立即测试）** —— 论文的主要协议贡献。
- **问题格式**：共 2,494 道六选一 MCQ（83.3%）和 500 道开放题（16.7%）。MCQ 答案位置用固定种子均匀打乱；干扰项设计为结构相似（中位绝对长度差 5 字符，52.9% 的干扰项在 5 字符内）。

## 6. 主要结论与发现

- **发现 1：存在广泛且依赖模型的记忆增益缺口**。全上下文使所有模型准确率提升 1.5–2.4×（从 0.18–0.27 升至 0.41–0.47），说明参数知识无法替代人物具体证据。但没有任何配置超过约 0.47 总体准确率或约 39% 的 MCQ 准确率，基准远未饱和。
- **发现 2：简单检索优于专用记忆系统**。在固定基座下，BM25 和 BGE-M3 检索恢复了约 88% 的上下界差距，而结构化/档案系统（Mem0、MemOS、Memobase）仅恢复 54–79%。差异集中在开放题上：检索保留的逐字证据比摘要更能支撑推理。但若考虑 token 效率，Mem0 最省 token；bge_rag 用 1.40k 而非 12.8k token 就能达到 88% 的上界恢复率，边际效率高 12 倍。
- **发现 3：记忆失败主要发生在“偏好信号”而非“事实”**。MemOS 在事实回忆上接近 full_context（27.7 vs 27.1），但在偏好追踪（31.9 vs 52.9）和偏差识别（32.6 vs 54.0）上大幅落后，说明摘要记忆“保事实、丢偏好”。
- **发现 4：Post-Shock 是独立的更新能力测试**。full_context 与 Mem0 的差距从 In-timeline 的 8.0 扩大到 Post-Shock 的 13.0，而零记忆控制仍在地板附近，说明事件冲击后的记忆整合是独特瓶颈。
- **发现 5：没有单一模型在所有能力上领先**。Claude 在事实回忆和因果推理领先，Qwen3.8 在偏好追踪和情境适应领先，Gemini 在跨域迁移领先——总体模型强度不等于个性化记忆优势。
- **发现 6：错误模式具有模型指纹**。零记忆默认是头号错误来源（占约 66% 认知失败），其次是单信号过度推断和时间错位；GPT-5.6-sol 尤其易犯单信号过度推断与时间错位。
- **发现 7：反典型类型人物上所有模型得分普遍降低**（低 4.5–11.2 点），表明模型会退回类型刻板印象，无法用个体证据推翻熟悉画像。

- **可审计的生成流程**：用确定性理论规则（Layer 1）约束 LLM 生成（Layer 2），再加自动校验/重试（Layer 3），极大降低生成器与评估目标纠缠的问题，保证语料可复现、可审计。
- **理论依据充分**：整合了前景理论（Tversky & Kahneman 1992）、经验效应（Malmendier & Nagel）、记忆参考依赖（Bordalo et al. 2020）、时变风险厌恶（Guiso et al. 2018）等行为金融经典机制，为规则设计提供合理性基础。
- **Post-Shock 检查点设计新颖**：直接测试智能体是否将重大事件整合进持久用户模型，且能定位“更新失败”而不是一般性遗忘。
- **归因分析立体**：从能力轴、失败模式、典型/反典型人物、时间检查点等多个维度拆分性能，识别出“事实 vs 偏好”“回忆 vs 更新”等不同瓶颈。
- **开放发布**：公开语料、规则引擎、模型标识、提示词、种子，便于复现与扩展。
- **问题设计严格**：多选干扰项结构与长度匹配良好（中位长度差 5 字符），降低表面启发式答题的可能性。

## 8. 不足与局限

- **合成数据固有局限**：persona 与偏好变化均由规则生成，基准上的得分不等于真实投资者场景下的性能；缺少真实用户交互验证。
- **时间跨度限制**：每个 timeline 仅包含 5–8 个事件，且集中在个人金融领域，未覆盖更长历史或非金融领域。
- **单种子与单基座**：记忆系统对比仅用 Qwen3.7-Max 一种基座、单一种子，未提供方差和跨基座稳健性检验。
- **预算不匹配**：各记忆系统使用原生 token 预算，full_context 约 12.8k 而检索系统约 1.4k，论文承认“描述操作点而非受控架构质量”，因此架构优劣不能完全归因于算法本身。
- **评测协议依赖第三方 API**：部分模型（Claude-Opus-4-8、GPT-5.6-sol）的 35 个查询因网关内容安全过滤器被丢弃（n=2959），可能引入轻微样本偏差。
- **开放题自动评判的局限**：LLM-as-a-judge 采用跨厂商多数投票，但未报告评判者与待评估模型之间的潜在偏好偏差（尽管 PT-Bench 方法学上常见）。
- **零内存控制组的干扰项污染疑点**：论文提到 76% 的零内存 MCQ 是“按设计”置于控制组，这可能导致某些能力指标被低估；虽然移除后情境适应和跨域迁移仍最难，但对指标解释需谨慎。
- **未涉及用户隐私、安全或道德评估**：在金融等高风险场景中，错误更新或过度自信偏差（MemFid 最高仅 1.97/5）的实际危害未被讨论。
