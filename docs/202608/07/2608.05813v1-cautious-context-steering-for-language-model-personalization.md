## 摘要
将语言模型（LM）个性化以适应每位用户的偏好，对于使回答与不同的目标和背景保持一致至关重要。现有方法通常为每个用户训练一个单独的适配器，或学习一个其得分依赖于用户的奖励模型。尽管这些方法为每个用户显式优化，但它们必须从有限的观测中学习，因此遭受数据稀疏性以及对未见用户和领域泛化能力差的问题。上下文学习（ICL）和上下文引导（CoS）可以通过直接基于用户上下文条件化基础LM，并利用其预训练能力而无需逐用户训练，从而提供更有效的个性化。然而，两者都没有在解码步骤中调整该上下文的影响：ICL使其不受控制，而CoS应用固定的引导系数并要求每步进行两次LM前向传播。我们提出了谨慎上下文引导（CCS），它向冻结的主干LM添加一个轻量级适配器，以在每个token处决定用户上下文是否以及以多强的程度影响生成。该适配器从预言机的上下文条件化LM中学习此行为，并在上下文无帮助时保留基础LM。仅在单一数据集上训练的一个CCS适配器既提高了域内生成质量，也提高了跨四个分布外个性化基准的生成质量，展示了对新用户和领域的稳健泛化。CCS还避免了逐用户微调和CoS所需的额外上下文条件化前向传播，大幅降低了推理成本。

## Abstract
Personalizing language models (LMs) to individual user preferences is essential for aligning responses with diverse goals and backgrounds. Existing methods typically train a separate adapter for each user or learn a reward model whose scores depend on the user. Despite explicitly optimizing for each user, these methods must learn from limited observations and therefore suffer from data sparsity and poor generalization to unseen users and domains. In-context learning (ICL) and Context Steering (CoS) can instead provide more effective personalization by conditioning the base LM directly on user context and leveraging its pretrained capabilities without per-user training. Yet neither adapts the influence of that context across decoding steps: ICL leaves it uncontrolled, whereas CoS applies a fixed steering coefficient and requires two LM forward passes per step. We propose Cautious Context Steering (CCS), which adds a lightweight adapter to a frozen backbone LM to decide at each token whether and how strongly user context should affect generation. The adapter learns this behavior from an oracle context-conditioned LM and preserves the base LM when the context is not helpful. A single CCS adapter trained on only one dataset improves generation quality both in-domain and across four out-of-distribution personalization benchmarks, demonstrating robust generalization to new users and domains. CCS also avoids per-user fine-tuning and the additional context-conditioned forward pass required by CoS, substantially reducing inference cost.

## 1. 核心问题与整体含义

- **研究背景**：语言模型（LM）的个性化对齐十分重要，需要让模型针对不同用户的偏好、目标和背景生成不同回答。现有方法主要分为两类：
  - **基于学习的方法**：为每个用户训练独立适配器，或训练依赖用户身份的奖励模型。这类方法受限于每个用户只有少量偏好数据（数据稀疏），难以泛化到未见用户和未见领域，且部署时需管理大量用户专属模型。
  - **基于上下文的方法**：ICL 直接将用户上下文拼接到提示中，依赖基础 LM 的上下文学习能力；Context Steering (CoS) 通过两个前向传播计算“上下文 logits 与基础 logits 之差”，再用固定系数 λ 进行放大或衰减。
- **核心问题**：ICL 对上下文影响不加控制；CoS 对所有 token 使用统一固定引导强度，且每步需要两次 LM 前向传播，成本高，还可能放大误导性上下文。
- **整体含义**：本文提出 **Cautious Context Steering (CCS)**，即“谨慎”的上下文引导——在冻结主干 LM 上增加轻量适配器，逐 token 决定是否使用用户上下文以及使用的强度，从而在保证个性化效果的同时提升泛化能力和推理效率。

## 2. 方法论

### 2.1 核心思想

- **关键词：谨慎（Cautious）**。用户上下文只应在它对当前 token 预测有可靠证据时影响生成；否则保留基础 LM 的行为。
- 通过一个小型适配器（参数少于主干 LM 的 1%）在推理时直接预测每个“合理 token”所需的 logit 偏置。

### 2.2 技术细节与关键公式

- **合理 token 集合** \(P_t\)：
  - 仅对基础 LM 当前概率较高的 token 集合进行引导，集合大小随基础分布的不确定性动态调整：基础 LM 越不确定，\(P_t\) 越大。
  - 集合外的 token 不添加偏置，保留其相对概率。

- **CCS 适配器**：
  - 将当前隐藏状态 \(h_t\)、提示表示和编码后的用户历史 \(H_u\) 融合为个性化状态 \(z_t\)。
  - 预测每个合理 token \(v \in P_t\) 的带符号引导分数：\(s_{\theta t}(v) = f_\theta(z_t, \ell^{\text{base}}_t(v))\)。
  - 另一个门控头预测谨慎门 \(g_t \in [0,1]\)，表示当前步骤是否应使用上下文。
  - 最终偏置：\(\delta_{\theta t}(v) = g_{\theta t} \cdot s_{\theta t}(v)\)。
  - 最终 logits：仅在 \(P_t\) 内加偏置，否则保持基础 logits。

- **谨慎蒸馏（Cautious Distillation）**：
  - 使用已有的上下文条件 LM（teacher）计算 token 级引导方向（与 CoS 相同），但只蒸馏“有用”的位置。
  - 定义引导优势（steering advantage）：\(A_t = \log p^{\text{ctx}}_t(y^+_t) - \log p^{\text{base}}_t(y^+_t)\)。
  - 设定 margin \(m\)，将位置分为：
    - \(T_{\text{help}}\)：\(A_t > m\)，上下文有帮助，学习 teacher 的引导方向。
    - \(T_{\text{preserve}}\)：\(A_t \leq m\)，学习保留基础分布。
  - 在 \(T_{\text{help}}\) 中，进一步计算 oracle 引导强度 \(\lambda^*_t\)，即在一定范围内最大化参考 token 概率的系数，并用它构造目标分布 \(q^*_t\)，然后通过 KL 散度蒸馏到学生分布。
  - 门控目标 \(\tilde{g}_t\) 由优势值经 sigmoid 映射得到，并用二分类交叉熵训练。

- **总损失**：\(L_{\text{CCS}} = \eta_{\text{help}} L_{\text{help}} + \eta_{\text{preserve}} L_{\text{preserve}} + \eta_{\text{gate}} L_{\text{gate}}\)。

### 2.3 推理流程

- 用户上下文仅编码一次，整个生成过程复用。
- 每步只用一次基础 LM 前向传播，然后由 CCS 适配器输出门控偏置，加到基础 logits 上形成个性化分布。
- 与 CoS 相比，省去了额外的上下文条件前向传播，显著降低开销。
