## 摘要
大型语言模型（LLM）智能体可以检索记忆、调用工具、提出澄清问题并调整回复风格，但将这些执行决策适应用户个人仍然困难。对专有系统进行微调单独的LLM成本高昂或不可行，而提示和记忆主要将用户信息暴露给智能体，而不是根据反馈调整其执行决策。我们将冻结智能体的个性化定义为从仅对已执行操作观察到的标量反馈中在线学习每个用户的执行策略。我们提出了FABLE（用于执行的因子化自适应波段层），这是一个位于潜在黑盒宿主智能体外部的轻量级策略层。FABLE对记忆、信息获取和响应决策进行因子化，使反馈更新相关选择；在探索之前通过外部指定的可行集过滤操作；并通过贝叶斯上下文汤普森采样学习相对于固定默认成本分数的用户特定残差偏好。在线性残差奖励模型下，校准变体继承了针对最佳可行动作的期望遗憾界。我们还描述了在持续性可行性约束下无法识别的偏好，并提供了随时有效的虚假提升控制。在个性化推理、受控反馈和可执行工具使用评估中，FABLE在几个偏好敏感行为上相对于仅规则控制有所改进，同时在端到端任务性能上保持竞争力。

## Abstract
Large language model (LLM) agents can retrieve memory, call tools, ask clarifying questions, and vary response style, yet adapting these execution decisions to an individual user remains difficult. Fine-tuning a separate LLM is costly or impossible for proprietary systems, while prompts and memory primarily expose user information to the agent rather than adapt its execution decisions from feedback. We formulate personalization of a frozen agent as online learning of a per-user execution policy from scalar feedback observed only for the executed action. We propose FABLE (Factorized Adaptive Bandit Layer for Execution), a lightweight policy layer outside a potentially black-box host agent. FABLE factorizes memory, information-acquisition, and response decisions so feedback updates related choices; filters actions through an externally specified feasible set before exploration; and learns user-specific residual preferences relative to a fixed default-and-cost score via Bayesian contextual Thompson sampling. Under a linear residual-reward model, a calibrated variant inherits an expected-regret bound against the best feasible action. We also characterize preferences unidentifiable under persistent feasibility constraints and provide anytime-valid false-promotion control. Across personalized-reasoning, controlled-feedback, and executable tool-use evaluations, FABLE improves several preference-sensitive behaviors relative to rule-only control while remaining competitive on end-to-end task performance.

- **研究背景**：LLM 智能体虽具备检索记忆、调用工具、追问澄清、调整回复风格等能力，但如何将这些"执行决策"适配到个体用户仍是开放问题。同一旅行规划请求，一位用户可能希望检索历史行程、在线核验选项并确认预订，另一位用户则可能禁止记忆访问、要求直接答复。
- **现有方法的缺口**：
  - 逐用户微调成本高昂，且对专有 API 模型不可行；
  - 提示（prompt）与记忆系统只是把用户信息暴露给模型，并不会根据用户后续反馈修订执行决策；

## 2. 方法论

### 2.1 核心思想

FABLE（Factorized Adaptive Bandit Layer for Execution）是一个位于冻结宿主智能体外部的轻量贝叶斯策略层，核心思路是：

1. **因子化动作空间**：将执行决策分解为记忆模式 m、信息获取模式 τ、响应行为 s，即 a = (m, τ, s)；
2. **残差偏好建模**：不从头学习完整效用，而是学习用户相对于固定默认-成本评分（default-and-cost score）的残差偏好；
3. **稀疏反馈共享**：单个标量反馈通过因子化特征更新相关动作方向，而非逐个组合独立学习；
4. **可行性优先**：硬约束（权限、工具可用性、强制确认、安全规则）在探索之前过滤动作，而非作为代价项参与评分；
5. **可修正入模**：onboarding 信息作为有限精度伪观测初始化后验，可被后续行为反馈修订。

### 2.2 关键技术细节

- **上下文适配器**：将请求 Xt、交互历史 Ht−1、非偏好背景 Qbg、硬状态 Qhard_t 映射为策略上下文 Ct = (kt, rt, gt, pt, qt)，分别表示任务类型、风险、模糊度、记忆需求、信息获取需求。
- **因子化特征映射**：
  - φ(c, a) 包含主效应 φM(m)、φT(τ)、φS(s)、上下文-组件交互 φC×M、φC×T、φC×S 以及组件间两两交互 φM×T、φM×S、φT×S；
  - 低阶交互在共享反馈与保留互补性之间取得平衡；过高阶交互退化为扁平动作表。
- **残差奖励模型**：
  - E[yt | Ct = c, at = a] = b(c, a) + φ(c, a)ᵀθ* − λ·cost(c, a)
  - 其中 b(c,a) 为固定默认分，cost(c,a) 为固定操作代价，θ* 为用户的真实残差偏好参数；
  - 只学习 θ*，保留宿主通用行为并暴露可审计的代价权衡。
- **可修正入模机制**：
  - onboarding 编码器将 Qpref 映射为 J 个伪观测 (vj, uj, κj)，其中 vj 为偏好方向、uj ∈ [−1,1] 为符号响应、κj ≥ 0 为精度；
  - 起点先验 N(μbase, Σbase)，通过 Σ₀⁻¹ = Σbase⁻¹ + Σ κj vj vjᵀ 和对应信息向量更新得到初始后验；
  - 有限精度保证不确定性保留，行为反馈可以修正冷启动偏差。
- **可行集过滤后的汤普森采样**：
  - 每轮由外部系统提供非空可行集 At ⊆ A，硬约束在此阶段强制生效；
  - 只采样残差参数：θ̃t ∼ N(μt, νt² Σt)，通过 argmax [ b̄(Ct,a) + φ(Ct,a)ᵀθ̃t ] 选动作；
  - 后验更新：Λt+1 = Λt + σ⁻²φtφtᵀ，ht+1 = ht + σ⁻²φtỹt（ỹt 为残差反馈）。
- **偏好提升规则**（附录 G）：预设可识别对比方向 wℓ，只有其任意时间置信序列排除零且证据计数达到阈值时才写入持久状态；提升不修改后验递推，具有任意时间有效的错误提升控制。
- **可选坐标稀疏子因子化**（附录 D）：FABLE-SPCA 从已有因子化坐标中选取子集，通过坐标稀疏 PCA 目标最小化 onboarding 加权的遗漏预测方差，在大约低维子空间上获得样本效率优势。

## 6. 主要结论与发现

1. **tau2 主实验**：
   - FABLE (full) 取得最高观测个性化奖励（0.640）与对齐（0.717），并与 FABLE (frozen) 并列最高任务成功均值（0.625）；

   - 消融支持：因子化贡献对齐 +0.022（正区间）、在线适应贡献对齐 +0.024（正区间）、onboarding 贡献最大（对齐 +0.163、奖励 +0.071，均正区间）；任务成功不因这些机制而显著改善。
2. **PAHF**：FABLE (full) 在 Online Shopping 上奖励与成功均为最佳；在 Embodied Manipulation 上奖励高于 Rule-Only 但低于无 onboarding 变体，成功则最高；奖励与成功指标不总产生一致排序。
3. **Math500**：FABLE (full) 与 FABLE (no onboarding) 并列最高正确率（0.972）；显式给出完整档案的宿主获得最高对齐（0.795）；在线更新在全息对比中把成本感知奖励从 0.235 提升至 0.366。
4. **受控实验**：在线策略 18/20 vs 冻结 14/20，两个规范探针均按指定方向移动（当前信息探针 0.529→0.885，稳定信息探针 0.511→0.999），但样本量不足以达到统计显著。
5. **总体判断**：FABLE 对偏好敏感指标（合成对齐、个性化奖励）有可重复的改善，但并**不能**声称显著提升任务成功、一般人类偏好对齐、跨域一致增益或宿主非劣性。

## 8. 缺点与局限性

- **任务成功提升有限**：即使在 tau2 主实验中，对齐与奖励显著提升，任务成功（+0.017）也不显著，且宿主非劣性检验未通过；这意味着 FABLE 在“不损害任务完成度”这一关键保证上缺乏统计证据。论文自身也承认，个性化偏好可能引导策略走向与任务目标冲突的方向。
- **偏好信号依赖合成数据**：tau2 与 PAHF 的对齐分均由合成档案构造，而非真实用户标注；Math500 更是仅用单合成用户。这使得“FABLE 能提升人类偏好对齐”这一主张的生态效度受限。
- **探索成本未在指标中充分暴露**：在线性策略的探索阶段可能产生更多工具调用、更多轮次、更不稳定的回复，但实验主要报告累积指标，没有跟踪每轮服务质量方差或失败事件密度；对真实客户服务而言，这种波动可能产生不可忽视的体验风险。
- **高维因子化的实际收益未充分验证**：理论遗憾界随 d^{3/2} 增长，但实验中的动作空间只有 18 或 27 个完整动作；FABLE 对抗欠拟合或过拟合的优势，在更大、更真实且交互噪声更高的动作空间上没有被实证检验。
- **残差模型的先验敏感性**：默认-成本评分 b(c,a) 与成本权重 λ 作为外部需指定项，在实验中被固定为统一值；实际部署时这些参数高度依赖域知识，论文未讨论错误设定 b 或 λ 时的鲁棒性边界。
- **入模提升的不可控风险被轻描淡写**：虽然理论保证任意时间假提升控制，但持久写回用户偏好的机制在隐私与可解释性上缺少保护措施——用户无法感知自己的行为被泛化为持久规则，也没有“删除偏好”或“审计提升记录”的机制；隐私影响评估未被纳入讨论。
- **对比基线仍有遗漏**：未与更强的在线学习基线（如 Bayesian logistic bandit、Neural bandit、Contextual policy search with function approximation）对比；Global LinTS 与 Per-User LinTS 均使用线性模型，不能代表离线 RL 或增量策略优化社区的水平。
- **移植性说明不充分**：论文声称 FABLE 可适配任意冻结宿主，但评估中宿主仅基于一种模型家族（opus-4-8 / deepseek-v4 系列）；跨宿主、跨模型版本时的行为一致性未被检验，这与“黑盒通用性”的声称存在差距。

## 9. 与现有工作的关系

- **与轻量控制层（OLIVIA 等）的区别**：OLIVIA 学习跨用户共享的控制策略，而 FABLE 明确学习逐用户参数；同时 FABLE 不需要读取宿主内部隐藏状态，比依赖内部特征的中间件更具黑盒兼容性。
- **与提示个性化（Prompt Personalization）**：提示工程只能将用户信息静态嵌入上下文，无法根据反馈修订“是否检索”“是否追问”等执行决策；FABLE 将这类决策转化为可在线学习的带臂问题。
- **与在线 RL / bandit 用于 LLM 对齐**：主流工作（如 DPO-based online RLHF）需要访问模型权重与梯度，面向训练阶段；FABLE 面向推理/部署阶段，以纯黑盒 + 轻量状态更新为约束条件，是两种不同计算范式下的互操作方案。与 Contextual Bandit 文献的关系：因子化线性奖励 + 汤普森采样的总体框架沿用了经典 LinTS，但新增了可行集过滤、可修正伪观测先验、以及“提升规则”这一新机制，使其适配 LLM 执行层的特殊约束。
- **与 PrefDisco / 合成偏好基准**：Math500 实验直接借鉴 PrefDisco 风格，说明 FABLE 可被嵌入既有评测方案；但论文也承认此类基准的合成性，因此只能作为“证明机制有效”的必要条件而非充分证据。
- **对个性化领域“残差偏好”概念**：将个体偏好建模为相对默认基线的残差，类似于推荐系统与多任务学习中的残差/偏差分解（bias-variance decomposition），但作者将其体系化应用于 LLM 执行决策，并给出理论遗憾分析。

## 10. 影响与展望

- **对 LLM 部署范式的潜在影响**：FABLE 提供了一种“不触碰权重、不微调、不访问隐藏状态”的个性化路径，使端侧或专有 API 模型也能在推理时完成用户级适配；这对隐私敏感场景（医疗、金融、法律咨询）以及低成本大规模服务（客服、教师助手）可能产生实际推动。
- **对个性化研究方向的启示**：
  - 残差建模与因子化特征映射可被推广到更复杂的动作依赖结构；
  - “可修正先验”（onboarding）思想为冷启动与用户可控权设置提供了可计算框架；
  - “不可达偏好不可学习”的可辨识性边界的刻画，提示任何个性化方法都应先检查动作空间是否覆盖用户期望的偏好方向。
- **开放问题**：
  - 如何将反馈信号从标量扩展到结构化反馈（分属记忆、检索、风格各维度），以及与现有日志数据的结合；
  - 如何在更长时间尺度上处理偏好漂移与遗忘；
  - 如何为持久“提升”建立可审计、可撤销的机制；
  - 如何降低探索对任务成功率的短期损害（例如通过安全探索约束或离线预训练初始化）。
- **理论层面的后续工作**：遗憾分析可扩展到非线性奖励（如高斯过程）、非平稳偏好或非Ⅰ级可行集（带有可学习成本的约束）；当前 Theorem 1 的 d^{3/2}√n 遗憾界虽保证了收敛性，但在动作维度较大时样本效率仍需进一步压缩。

## 11. 总评

FABLE 是一篇设计完整性很高的工作：它把一个此前被分散处理为“提示、记忆、工具选择”各自为政的问题统一为带严格约束的在线逐用户策略学习，并以理论和实验两个层面回应了“能否在不动宿主模型的前提下适配到个体”。其最大的贡献是**动作因子化与残差反馈的建模思路**——这让单次交互的稀疏反馈能被多个决策方向共享，打通了记忆、检索与风格之间的学习通道；同时，可行性过滤与可修正先验的设计也体现了工程落地中的严谨意识。

不过，其主张的边界必须被明确：论文展示的是**对合成偏好信号的可重复改善**，而非对真实人类偏好的普适性证明；“能提升任务成功/保证宿主非劣”的说法没有得到统计支持。对于任何将其结论推广到生产环境的读者，应将 FABLE 视为“个性化控制的基础层”而非“服务质量增强层”，需在真实用户与真实服务评估中进一步验证。

总体而言，这是一篇方法论价值较高的研究工作，在个性化 LLM 智能体的“执行决策层”这一新方向上迈出了扎实一步，值得后续在真实用户规模、跨模型泛化、可审计性与隐私机制上继续深入。
