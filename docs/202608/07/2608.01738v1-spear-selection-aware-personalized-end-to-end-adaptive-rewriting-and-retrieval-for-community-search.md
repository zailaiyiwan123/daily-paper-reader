## 摘要
查询改写连接了电子商务搜索中的用户意图与检索，但生产系统分别优化改写质量和检索效果，导致两个阶段结构上错位。基于路径的架构将它们端到端统一，但设计初衷是用于个性化，其中相关性不是显式约束——搜索还要求改写保持对用户明确查询意图的忠实。直接移植这些模型会学习到一种我们称之为“通用词主导效应”的捷径：它们偏向于在路径上得分高但偏离查询意图的通用改写。为了解决这个问题，我们提出了SPEAR（选择感知个性化端到端自适应改写与检索），它集成了三个组件，每个组件针对一种失败模式：（1）双嵌入主干，带有辅助损失和梯度隔离，保护召回侧语义不被CTR驱动的排序信号侵蚀；（2）乘法门控聚合器，只有当改写的置信度和物品相关性都强时，才允许改写得分高，从而消除通用词捷径；（3）动态改写选择器，联合生成请求特定的改写权重和用户查询条件的尺度和偏置项，使改写偏好和相关性校准都能适应每个请求。在10万次工业搜索会话上的离线评估表明，所提出的框架相对于生产基线，将改写语义相似度@10提高了+18.2，点击召回率@10提高了+99.5。在线A/B测试中，SPEAR在查询视图点击率上获得+0.259的提升，平均阅读深度提升+0.733，证实了改进的改写选择能转化为更强的检索和更深的用户参与。所提出的SPEAR系统自2025年起已全面部署在得物社区搜索平台。我们的代码可在https://github.com/mallocagi1-cell/spear获取。

## Abstract
Query reformulation bridges user intent and retrieval in e-commerce search, yet production systems optimize rewrite quality and retrieval effectiveness separately, leaving the two stages structurally misaligned. Path-based architectures unify them end-to-end but were designed for personalization, where relevance is not an explicit constraint-search additionally requires the rewrite to remain faithful to the user's stated query intent. Transplanted directly, these models learn a shortcut we term the generic-word dominance effect: they favor generic rewrites that score well on paths but drift from query intent. To address this, we propose SPEAR (Selection-aware Personalized End-to-end Adaptive Rewriting and Retrieval), which integrates three components that each target one failure mode: (1) a dual-embedding backbone with auxiliary loss and gradient isolation that shields recall-side semantics from being eroded by CTR-driven ranking signals; (2) a multiplicative gating aggregator that lets a rewrite score high only when both its confidence and item relevance are strong, eliminating the generic-word shortcut; (3) a Dynamic Rewrite Selector that jointly generates request-specific rewrite weights and user-query-conditioned scale and bias terms, allowing both rewrite preference and relevance calibration to adapt to each request. Offline evaluation on 100K held-out industrial search sessions shows that the proposed framework improves rewrite semantic similarity@10 by +18.2 and click recall@10 by +99.5 over the production baseline. In online A/B testing, SPEAR achieves +0.259 in query-view CTR and +0.733 in average reading depth, confirming that improved rewrite selection translates into stronger retrieval and deeper user engagement. The proposed SPEAR system has been fully deployed in Dewu's community search platform since 2025. Our code is available at https://github.com/mallocagi1-cell/spear.

## 1. 论文的核心问题与整体含义

**研究动机与背景：**
- 在电商搜索（特别是内容社区搜索）中，查询改写（Query Reformulation）是连接用户意图与检索系统的关键环节。生产系统通常采用**两阶段流水线**：先由改写模块生成/选择改写候选，再由下游检索模型消费这些改写。两个阶段分别以不同目标优化——前者优化语义相似度，后者优化用户参与（点击），导致**结构性目标错位**。
- **路径式端到端架构**（如 PDN）能够将改写选择与检索统一到一个可微分框架中，但 PDN 最初是为推荐系统设计，以用户参与为唯一目标，**不包含显式的相关性约束**。
- 将 PDN 直接移植到搜索场景会出现作者所称的**"通用词主导效应"（generic-word dominance effect）**：模型偏向高频通用改写词（如"手机壳""女装连衣裙"），这些词先验概率高、与大量物品共现，在加性路径聚合下仅靠选择置信度就能累积高分，但严重偏离用户的明确查询意图。
- 此外，CTR 优化的梯度会侵蚀检索侧（Recall）的语义表示结构，造成召回空间退化。
- 核心矛盾：**搜索必须在提升参与度的同时保持对原始查询意图的忠实**，即"相关性—参与度"的平衡。

## 2. 论文提出的方法论

**核心思想：**
SPEAR 以 PDN 风格架构为骨架（共享编码器主干），通过三个针对性结构修改，实现**选择感知（selection-aware）的端到端改写与检索联合优化**，使改写选择直接受下游点击反馈监督，同时保留语义忠实。

**三大核心组件：**

1. **双嵌入主干（Dual-Embedding Backbone）与梯度隔离**
   - 共享编码器输出后，经专用投影 MLP 分支为 Recall 域和 Rank 域两种表示。
   - Recall 域喂给 InfoNCE 语义对齐损失，维护召回侧语义几何结构。
   - Rank 域喂给点击评分系统。
   - 通过 **stop-gradient** 机制：`∇θ_rec L_main = 0`，防止 CTR 梯度侵蚀召回侧语义结构。
   - 关键动机：实验证明单一共享嵌入空间严重退化——类别纯度从 Recall 的 0.740 降至 Shared 的 0.229（表 4）。

2. **乘法门控聚合器（Multiplicative Gating Aggregator）**
   - 用**乘法**交互替代 PDN 的加性路径聚合。
   - 每条改写路径分数：`r_i = softplus(β(u)·sim(q_rank_i, d_rank) + b(u))`。
   - 最终改写路径得分：`s_rw = Σ α_i · r_i`。
   - softplus 保证非负，使 `α_i`（选择置信度）与 `r_i`（物品相关性）**必须同时高**才能贡献大幅得分——高置信 + 弱相关性（或反之）贡献趋近于零，直接消除通用词捷径。

3. **动态改写选择器（Dynamic Rewrite Selector）**
   - 构建用户-原查询交互表示：`c_i = h_int([h_u; q_emb_o]) ⊙ q_emb_i`。
   - 结合兼容性评分 `s_sel_i = sim(q_rec_o, q_rec_i)`（stop-gradient），经掩码 softmax 生成改写权重 `α_i`。
   - 同时通过轻量 MLP 生成请求特定的缩放因子 `β(u)` 和偏置 `b(u)`。
   - 改写选择从"离线预处理步骤"变为"带端任务反馈的可训练决策模块"。

**个人信息得分系统与训练目标：**
- 最终得分 = 改写路径（乘法门控加权和）+ 原查询直连路径（残差保障）。
- 主损失为点击二分类交叉熵（`L_main`），辅助损失为 Recall 域 InfoNCE（`L_NCE`，应用于原查询视图与改写聚合视图），最终目标：`L = L_main + λ_align·L_NCE + λ_reg·L_reg`。
- CTR 梯度更新共享编码器、Rank 分支与选择器；语义对齐更新共享编码器与 Recall 分支；梯度被显式路由隔离。

- **SPEAR 在离线评估中全面优于基线**：点击召回@10 从 0.1694 提升至 0.3380（相对 +99.5%）；曝光召回@10 从 0.1403 提升至 0.2949（相对 +110.2%）；语义相似度@10 从 0.6986 提升至 0.8258（相对 +18.2%）。

## 7. 优点

- **问题识别精准**："通用词主导效应"概念清晰，对路径式模型从推荐移植到搜索的失败模式给出了令人信服的解释。
- **方法论贡献扎实**：三大组件各有明确的失败模式对应，不是简单堆砌技巧；梯度隔离的公式化表述（`∇θ_rec L_main = 0`）简洁且可复现。
- **乘法门控的设计巧思**：利用 softplus 非负性使选择置信度与物品相关性形成严格乘法耦合，从结构上杜绝捷径而非依赖调参。
- **残差直连路径**：保留原始查询直接匹配，已对噪声改写数据有鲁棒性。
- **可解释性工作出色**：t-SNE 可视化 + 表 4 的定量指标（Purity、Eff. Rank Ratio、Inter/Intra）从表征几何角度直接验证了双嵌入隔离的必要性，这在工业论文中较为少见。
- **验证链完整**：离线消融 → 在线 A/B → 人工评估 → 案例分析，证据链从模型表现到用户感知全覆盖。
- **工程落地性强**：延迟开销仅 25ms/请求且无端到端额外延迟，系统已于 2025 年在得物生产环境全面部署。

## 8. 不足与局限

- **对比范围局限**：仅以生产 PDN 为基线，缺乏与 LLM 改写（如 BEQUE）、强化学习改写、循环一致翻译等方法的直接实验对比，难以判断 SPEAR 相对这些方向的绝对优势。
- **泛化性存疑**：只在得物一个平台验证，未在公开基准（如电商搜索标准集）或多平台工业数据上测试；方法有效性是否依赖社区搜索的特性（用户生成内容、消费意图混合）尚不明确。
- **评估偏差风险**：语义相似度由内部"生产级相关性模型"计算，其训练数据本身可能带有与 SPEAR 设计偏好一致的系统性偏差。
- **动态选择器单独使用时的不一致**：仅点击监督的 DRS 单独会降低语义相似度（-0.5%），说明其需要与其他组件配合才能保持意图忠实；若部署时组件不匹配可能出现类似问题。
- **在线提升绝对幅度较小**：CTR 提升 0.259%、阅读深度 0.733%，虽然显著但对于中小型平台能否复制同样效果没有保障。
- **保留率不显著**：D1/D7 留存虽正向但未达显著，长期用户价值证据不足。
- **算力资源未披露**：训练基础设施信息缺失，会影响可复现性评估。
- **未与 LLM 路线融合验证**：虽然作者声称 LLM 改写可作 drop-in 替代编码器主干，但未提供任何实验证据支持这一说法。
