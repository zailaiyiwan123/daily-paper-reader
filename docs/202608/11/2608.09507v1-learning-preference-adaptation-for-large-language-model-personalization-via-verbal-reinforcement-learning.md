## 摘要
自然语言用户偏好为大语言模型（LLM）个性化提供了一个可解释的接口。然而，通用的偏好摘要往往包含与特定下游任务无关的信息。直接提供完整的偏好摘要会浪费上下文容量并引入跨任务干扰，而手动设计任务特定的偏好视图则难以扩展。在这项工作中，我们研究了\emph{任务特定偏好自适应}：给定通用用户偏好摘要和下游任务，推导出保留足够决策相关证据同时去除冗余上下文的任务条件化表示。为此，我们提出了\textsc{AlignXada}，一种无需训练的元学习框架，它通过语言强化学习诱导出可复用的文本细化策略，用于将通用偏好摘要调整为任务特定摘要。在13个任务和三个下游模型（39个任务-模型单元）中，\textsc{AlignXada}平均提升了3.82分，改进了33个单元，同时仅保留了原始配置文件令牌的22.8%，并在36个单元中优于RAG。进一步的忠实性分析表明，细化后的配置文件在很大程度上仍基于源偏好，同时保留了与任务相关的个性化信号，这表明配置文件侧的自适应可以作为通用记忆构建的实际补充，用于终身个性化智能体。

## Abstract
Natural language user preferences provide an interpretable interface for LLM personalization. However, universal preference summaries often contain information irrelevant to a particular downstream task. Directly supplying the full preference summary therefore wastes context capacity and introduces cross-task distraction, while manually designing task-specific preference views is difficult to scale. In this work, we study \emph{task-specific preference adaptation}: given a universal user preference summary and a downstream task, derive a task-conditioned representation that preserves sufficient decision-relevant evidence while removing redundant context. To this end, we propose \textsc{AlignXada}, a training-free meta-learning framework that induces reusable textual refinement policies for adapting universal preference summaries to task-specific ones. The refinement policy is iteratively optimized by a meta learner through verbal reinforcement learning. Across 13 tasks and three downstream models (39 task--model cells), \textsc{AlignXada} achieves an average gain of 3.82 points, improving 33 cells while retaining only 22.8\% of the original profile tokens and outperforming RAG in 36 cells. An extended faithfulness analysis further shows that the refined profiles remain largely grounded in the source preferences while preserving task-relevant personalization signals, suggesting that profile-side adaptation serves as a practical complement to universal memory construction for lifelong personalized agents.

## 2. 方法论：AlignXada

### 2.1 核心思想

- 将“偏好细化策略”与“偏好细化执行”解耦：元学习器（meta learner）生成可复用的**文本细化策略（policy）**，冻结的细化器（refiner）依据该策略将通用偏好改写为任务特定偏好。
- 策略通过**语言强化学习（Verbal Reinforcement Learning）** 迭代优化——只有策略文本在更新，所有模型参数保持冻结，因此同时兼容开源与专有模型。

### 2.2 问题形式化

- 任务 $\tau$ 由支持集 $S^{(\tau)} = \{ (P_{u_i}, x_i, y_i) \}_{i=1}^{b}$ 指定，其中 $x_i, y_i$ 为用户的输入提示和参考响应。
- 学习目标：最大化期望任务分数
  $$ \mathbb{E}_{(P_{u_i}, x_i, y_i) \sim S^{(\tau)}} \left[ \text{Score}_\tau \left( M(x_i, \tilde{P}_{u_i}), y_i \right) \right] $$
  其中 $\tilde{P}_u = R(P_u, \phi^{(\tau)})$，$R$ 为冻结细化器，$\phi^{(\tau)}$ 为可学习的文本策略。

### 2.3 算法流程

1. **Rollout（滚动评估）**：在支持集每个示例上，细化器按当前策略重写配置文件，下游模型生成预测，并计算任务分数，记录为结构化 rollout 记录 $R_t$。
2. **反馈聚合**：将 rollout 记录聚合成结构化反馈 $E_t$，包含平均分数、预测结果、代表性失败模式等。
3. **策略更新**：冻结的元学习器 $\pi_{\text{meta}}$ 基于当前策略和反馈生成修订策略 $\phi_{t+1}$，要求遵循预定义策略模式、做针对性修改、避免记住特定样例。
4. **最优策略选择**：迭代 $T$ 轮后，从历史 $\mathcal{H}$ 中选择在开发集上得分最高的策略作为最终任务策略。

### 2.4 设计亮点

- 策略模式包含 Goal、Preserve、Compress、Avoid、Output Style、Priority 等结构化字段，保证策略可解释、可控。
- 自适应诊断采样：将支持示例按 outcome-transition 分为 improved / regressed / stable-success / persistent-failure 四类，均匀分配预算，给元学习器提供平衡的纠正与稳定信号。

## 3. 实验设计

### 3.1 基准（Benchmark）

- **复合基准**：整合 PersonaMem-v2 和 MemoryCD 两个数据集，通过语义匹配构造共享通用配置文件的复合用户。
- **13 个任务**：
  - 9 个 PersonaMem-v2 对话任务：Chat Message、Creative Writing、Knowledge Query、Personal Email、Professional Email、Professional Writing、Social Media Post、Translation、Trouble Consult。
  - 4 个 MemoryCD 任务：Item Ranking、Rating Prediction、Review Title Generation、Review Generation。
- **3 个下游模型**：Qwen3-8B、DeepSeek-V4-Flash、GPT-5-mini，总计 39 个任务–模型单元。

### 3.2 评估指标

- 四选一任务：准确率（Accuracy）
- 物品排名：Hit@1
- 评分预测：Rating-Score（$S(\hat{y}, y) = \max(0, 1 - |\hat{y} - y|/4)$）
- 文本生成：ROUGE-L
- 上下文效率：Token Ratio（TR）= 精炼后平均令牌数 / 通用配置平均令牌数

### 3.3 对比方法

- **Raw**：直接输入完整通用偏好摘要。
- **RAG**：BM25 检索配置块，预算约 768 tokens（TR ≈ 20%），与 AlignXada 精炼后长度相当。
- **AlignXada**：使用 Gemini-2.5-Pro 作为默认元学习器和细化器，DeepSeek-V4-Flash 作为替代泛化验证。

## 6. 主要结论与发现

1. **性能–效率权衡显著改善**：在 39 个单元中改善 33 个，平均 +3.82 分；三个下游模型分别 +2.27 / +7.00 / +2.19 分；精炼配置文件仅保留原始令牌的 22.8%，且性能增益与 token ratio 几乎不相关（$r = 0.06$）。
2. **优于 RAG**：在 36 个单元中优于 RAG，平均高出 +7.28 分；RAG 平均反而造成 3.46 分的下降。这说明任务导向的偏好重组超越了查询级别的检索。
3. **最优偏好表示依赖任务和模型**：同一任务不同模型上增益符号可能反转，如 Professional Email 上 Qwen3-8B 为 −1.50、DeepSeek-V4-Flash 为 +12.50、GPT-5-mini 为 −0.67，说明利用下游模型反馈来指导策略归纳是必要的。
4. **忠实性良好**：97.5% 的声明受源配置文件支持、非幻觉率 97.9%、非矛盾率 99.8%；条件于源配置包含金标证据时，83.3% 被精炼配置保留。
5. **瓶颈在于源配置的证据覆盖**：仅 34.0% 的金标准偏好能从源配置中恢复，精炼后保留 30.2%，与源证据上限差距不大——即主要限制来自上游偏好构造而非精炼过程。

## 8. 不足与局限

1. **基准数据的生态效度有限**：两个基准均为构造或策展数据集，可能无法完全反映真实终身代理中不断演变的、带噪的用户交互。作者在 Limitations 中也承认这一点。
2. **支持集代表性假设**：AlignXada 假设支持集能代表目标任务分布，若支持集偏差或不充分，策略泛化性能可能下降。
3. **部分任务负增益**：Knowledge Query 在 DeepSeek 和 GPT-5 上有 −0.06 和 −1.58 的轻微回归；某些任务在固定采样下负增益明显，说明策略稳定性仍有提升空间。
4. **源配置的证据覆盖率是硬瓶颈**：如果通用偏好本身缺少决策所需证据，无论精炼策略多好都无法恢复（Source Coverage 仅 34%），因此效果受上游偏好构造质量制约。
5. **算力报告缺失**：未报告训练/推理调用成本，可复现性和可持续性评估不完整。
6. **同模型族内部对比受限**：跨元模型实验只测试了 DeepSeek-V4-Flash，未覆盖更强的开源模型或多个闭源模型之间的交互效应。
