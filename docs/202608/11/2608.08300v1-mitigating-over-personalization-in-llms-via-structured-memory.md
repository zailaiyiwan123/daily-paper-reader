## 摘要
对话助手越来越依赖持久的长时记忆来跨会话个性化响应。然而，当存储的用户信息被重新引入模型上下文时，它也可能在不适当或不相关的场景中影响响应。我们研究了记忆增强型大语言模型中的两种此类失败模式：跨领域泄漏（一个生活领域的记忆影响另一个领域的响应）和记忆引发的谄媚（存储的用户信念使模型更倾向于同意用户而非如实回答）。我们应用了一种简单的推理时修改，改变记忆呈现给模型的方式，而不改变模型或记忆内容。在PersistBench上的七个模型中，我们比较了常用的全上下文格式（记忆作为非结构化列表注入）与按领域划分记忆的结构化格式。这种简单的修改一致地减少了跨领域泄漏，同时保持了实用性，我们最强的方法相对于基线平均减少了$8.8\%$的泄漏。

## Abstract
Conversational assistants increasingly rely on persistent long-term memory to personalize responses across sessions. However, when stored user information is reintroduced into the model context, it can also influence responses in inappropriate or unrelated settings. We study two such failure modes in memory-augmented LLMs: cross-domain leakage, where memories from one life domain affect responses in another, and memory-induced sycophancy, where stored user beliefs make models more likely to agree with the user rather than respond truthfully. We apply a simple inference-time modification to how memories are presented to the model, without changing the model or the memory contents. Across seven models on PersistBench, we compare the commonly used all-in context format, where memories are injected as an unstructured list, with structured formats that partition memories by domain. This simple modification consistently reduces cross-domain leakage while preserving utility, with our strongest method reducing leakage by $8.8\%$ on average relative to the baseline.

## 一、论文的核心问题与整体含义（研究动机与背景）

- **研究背景**：对话助手（如 ChatGPT、Claude、Gemini）越来越多地依赖持久化长期记忆（persistent long-term memory）跨会话个性化响应。当前工业界的主流范式是将用户记忆作为非结构化列表直接注入系统提示词（system prompt）中，使模型在每次生成时都能看到全部记忆。
- **核心问题**：记忆增强虽提升个性化效用，但会引入两类安全相关失败模式：
  1. **跨领域泄漏（Cross-domain Leakage）**：一个生活领域（如健康、财务）的记忆不适当地影响另一个无关领域（如工作、社交）的响应，可能泄露敏感个人信息或导致回应失当。
  2. **记忆诱导的谄媚（Memory-induced Sycophancy）**：存储的用户信念或身份属性使模型倾向于迎合用户观点，而非追求知识上的真实性。
- **关键观察**：现有方法大多假设记忆必须以“扁平列表”形式注入上下文。该文挑战了这一假设，探索仅改变记忆的**呈现方式**（而非模型参数或记忆内容）能否缓解上述失败模式。
- **整体含义**：记忆的组织与结构本身就是一项安全关键设计。简单的推理时修改——将记忆按领域分区——即可在不牺牲个性化效用的情况下显著降低跨域泄漏，为长期记忆助手提供**低成本、即插即用**的安全改进思路。

## 二、方法论

### 2.1 核心思想
将原本作为单一扁平列表注入的记忆块 M，替换为按生活领域分区的结构化表示 M′，同时保持记忆内容与模型参数完全不变。任务输入表示为：
```
I = S + M + q
```
其中 S 为系统提示，M 为记忆块，q 为用户查询。论文提出的方法仅替换 M 为 M′，并可附加提示防御增强 S。

### 2.2 三种结构化记忆方法

1. **固定领域分区（Fixed Domain Partitioning）**
   - 使用预定义分类法（11个固定领域）：health、identity、social、romantic、personal、education、employment、finance、housing、legal、schedule（受 Nissenbaum 的语境完整性理论启发）。
   - 由一个 LLM 分类器 f_c 将每条记忆映射到唯一领域：`f_c: M → D`。
   - 渲染格式：在每个领域标题（如 `Personal:`、`Health:`）后列出来自该领域的记忆。

2. **动态领域分区（Dynamic Domain Partitioning）**
   - 在固定分类法基础上，允许分类器在推理时引入**自定义领域（D_c）**，以处理固定分类法未覆盖的、但记忆集中确实存在的有凝聚力的生活领域。
   - 约束：最多新增 2 个自定义类别，不允许与已有类别含义重叠，且必须有至少一条记忆支撑。
   - 映射为：`f_c: M → D₀ ∪ D_c`。
   - 优点是能对记忆集自适应，让分类边界更贴近实际数据分布。

3. **记忆树分区（Memory Tree Partitioning）**
   - 采用两步分类器：
     - 第一步，提议器 f_p 为每个顶层领域提出子类别（subcategories），形成“树骨架”；
     - 第二步，分类器 f_c 将每条记忆分配到唯一叶子节点。
   - 树深度限制为 2 层（避免过度碎片化），每个领域子类别最多 7 个。
   - 渲染格式：领域 > 子领域 > 记忆。

### 2.3 与基线对比
- 基线包括：扁平记忆列表（Flat List）、提示指令防御（Defense Prompts）、检索增强（RAG，按余弦相似度截断记忆）。
- 论文强调：**只改变记忆的组织与呈现方式，属于推理时一次性的预处理**，不像提示词防御那样每个查询都要消耗大量 token 或持续调优。

## 六、论文主要结论与发现

1. **结构化记忆减少跨域泄漏**：
   - 动态分区（Dynamic Partitions）在所有 7 个模型中均降低跨域泄漏，平均降低 **8.8%**（相对值），标准差 4.6%；
   - 最大降幅：DeepSeek V3.2（69.0%→55.0%）、Qwen 3-235B（80.0%→66.5%）、GLM-4.7（58.5%→48.0%）、GPT-OSS 120B（51.0%→41.0%）。
2. **动态分区在保持有益个性化方面最优**：
   - 固定分区轻微增加有益记忆失败率（23.3%→24.4%）；
   - 动态分区同时降低有益记忆失败率（23.3%→20.7%），实现更优的帕累托权衡，即泄漏与效用“双赢”。
3. **RAG 的泄漏抑制是以牺牲记忆效用为代价**：τ=0.50 时跨域泄漏降至 24.4%，但有益记忆失败率飙升至 71.3%，说明这是一种粗暴的“丢弃记忆”策略而非真正的安全控制。
4. **记忆诱导的谄媚极难通过结构调整缓解**：
   - 基线谄媚失败率已接近天花板（平均约 96.5%），结构化记忆仅将其降至约 95%，实际效果有限，需其他干预（如训练时校准）。
5. **与提示词防御互补**：
   - 动态分区可与 Restrictive、Rubric-informed、GEPA Optimized 提示防御叠加使用，带来一致但小幅的额外改进（如 GEPA 下 CD 从 56.2% 降至 52.5%，Benf. 从 19.4% 降至 17.1%）。
6. **基于定性分析的机制解释**：
   - 分区有效条件：记忆领域归属清晰、查询领域明确；
   - 失效模式：记忆被错误分类到错误领域，或一条记忆同时关联多个领域（导致模型在领域之间“跳跃”）。

## 七、优点与亮点

- **方法极简、零训练、零参数修改**：仅改变记忆的分组与标签格式，即可在多个模型上获得一致的泄漏缓解效果，工程部署门槛低、可迁移性强。
- **与现有防御体系正交且互补**：结构化记忆可以与提示词防御、RAG 等组合使用，形成一个低成本安全层。
- **系统性和全面性**：7 个模型、5 种防御提示、6 种方法、三个子集指标，配以多层分析（热图、逐样本重叠、领域对矩阵、定性堆栈），证据链完整。
- **成本透明**：给出详尽的 API 成本、token 用量，并论证部署时一次性分区成本可忽略（还可换用更小的模型做分类），实践参考价值高。
- **理论联结**：将记忆分区建立在“语境完整性”（Contextual Integrity）框架之上，使方法论有伦理学支撑，而非单纯工程技巧。
- **诚实报告局限性**：明确承认对谄媚几乎无效、仅测试单一 benchmark 等。

## 八、不足与局限

- **基准单一性**：仅用 PersistBench 一个基准，且其平均每查询记忆数仅约 16 条；真实部署中用户可能积累几百条记忆，组织难度和泄漏风险可能更高。
- **样本量偏小**：500 样本（跨域 200、谄媚 200、有益 100），统计功效有限，置信区间较宽；样本分布不均（如 Beliefs 是最主要记忆源、Work 是最多查询目标，多对领域组合稀疏甚至空缺）。
- **依赖分类器质量**：分区效果取决于 LLM 分类提示、分类法、分类器模型的选择；不同分类器可能产出不同结构，结果的可复现性和泛化性有待更大范围验证。
- **谄媚问题未获实质缓解**：结构化记忆对 memory-induced sycophancy 几乎没有效果（基线即天花板），说明此类问题需要记忆组织之外的干预（如训练时反谄媚微调）。
- **自动评估的偏差风险**：仅依赖一个 judge 模型（Kimi-K2-Thinking），可能存在系统性判断偏差；未报告人工评估的一致性验证。
- **“跨域泄漏”的定义依赖标注**：PersistBench 的失败判定依赖最大 judge 分数≥3，阈值和定义可能影响比较的公平性。
- **两棵树的额外开销**：两级树方法需要两次分类器调用，成本高一倍左右，而收益不如动态分区明显，其性价比有待进一步权衡。
- **模型覆盖面无 RLHF 对齐类模型之外的验证**：未测试更多规模、架构或本地小模型上的稳定性（如 7B 级模型），也未验证该方法在长期、真实交互数据上的效果。
