## 摘要
我们开发了一种新方法，用于跨异构客户端的个性化联邦学习，基于非参数经验贝叶斯（NPEB）。利用经验风险最小化或M估计获得的局部参数估计的渐近正态性，我们的方法将这些估计视为带噪声的观测，通过非参数最大似然估计未知的共享先验。在此设置中应用NPEB的一个关键挑战是现有方法假设已知固定方差，而这在实际中并不成立。为了解决这个问题，我们引入了一种方差感知非参数经验贝叶斯（VANEB）框架，利用局部M估计的参数依赖渐近方差。一个关键的技术贡献是针对这种异方差设置的广义Tweedie公式。然后，我们建立了平均平方Hellinger距离下密度估计的非渐近误差率，并推导了一个oracle去噪不等式，为我们的估计器提供误差界。虽然我们的理论保证植根于M估计的渐近机制，但我们经验性地探索了VANEB对涉及深度神经网络（DNN）的现代联邦学习设置的启发式扩展。对于DNN，我们提出了VANEB-head和VANEB-FT，通过使用近似对角方差估计器的NPEB步骤个性化最后一个全连接层。我们展示了我们的方法在使用卷积神经网络架构的流行视觉数据集MNIST和CIFAR-10上具有强大的性能。

## Abstract
We develop a new approach to Personalized Federated Learning across heterogeneous clients using Nonparametric Empirical Bayes (NPEB). Leveraging the asymptotic normality of local parameter estimates obtained from Empirical Risk Minimization or M-estimation, our method formulates these estimates as noisy observations to estimate an unknown shared prior via Nonparametric Maximum Likelihood. A key challenge in applying NPEB in this setting is that existing approaches assume known fixed variances, which is not true in practice. To address this, we introduce a Variance-Aware Nonparametric Empirical Bayes (VANEB) framework that leverages the parameter-dependent asymptotic variance of local M-estimators. A key technical contribution is a generalized Tweedie's formula for this heteroskedastic setting. We then establish non-asymptotic error rates for density estimation in the average squared Hellinger distance and derive an oracle denoising inequality that provides error bounds for our estimator. While our theoretical guarantees are rooted in the asymptotic regime of M-estimators, we empirically explore heuristic extensions of VANEB to modern federated learning settings involving Deep Neural Networks (DNNs). For DNNs, we propose VANEB-head and VANEB-FT, which personalize the last fully connected layer via an NPEB step using an approximate diagonal variance estimator. We show that our method has strong performance on popular vision datasets MNIST and CIFAR-10, using a convolutional neural network architecture.

## 论文核心问题与研究动机

- 联邦学习（FL）中客户端数据分布高度异构，单一全局模型难以对每个客户端都表现良好，因此需要**个性化联邦学习（PFL）**。
- 现有非参数经验贝叶斯（NPEB）方法（如基于 NPMLE 的 Gaussian denoising）大多假设**已知且固定的方差/协方差结构**，这在联邦学习中通常不成立：
  - 客户端本地 M-estimator（如 MLE、GLM 估计）的渐近协方差矩阵**未知，且通常依赖于被估计的客户端参数 θ**（例如 Fisher 信息矩阵的逆）。
  - 若忽略这种参数依赖的异方差性，直接套用固定协方差 NPEB，会导致先验估计偏差和去噪问题被错误加权。
- 本文试图将个性化联邦学习视为一个**复合决策问题（compound decision）**，用经验贝叶斯思想统一：服务器只接收客户端本地估计量，学习潜在共享先验，再进行客户端专属的贝叶斯收缩。

## 论文提出的方法论

### 核心思想

- 将客户端本地 M-estimator 的渐近正态性作为工作模型：
  \[
  \sqrt{n_k}(\hat\theta_k - \theta_k) \mid \theta_k \sim N(0, \Sigma_k(\theta_k))
  \]
  其中 \(\Sigma_k(\theta)\) 为**参数依赖的协方差函数**。
- 将 \(\theta_k\) 视为来自未知先验 \(G_0\) 的独立样本，服务器根据所有客户端的观测 \(\{\hat\theta_k\}\) 通过非参数最大似然（NPMLE）估计 \(G_0\)，再计算各客户端的后验均值作为个性化估计。

### 关键技术与算法流程

1. **广义 Tweedie 公式（generalized Tweedie’s formula）**
   - 经典 Tweedie 公式要求协方差矩阵与 θ 无关；本文推导了参数依赖协方差 \(\Sigma_k(\theta)\) 情形下的扩展公式：
   \[
   \theta_k^o = \frac{\hat\theta_k}{\sqrt{n_k}} + \frac{q_{k,G_0}(\hat\theta_k)}{\sqrt{n_k} f_{k,G_0}(\hat\theta_k)}
   \]
   其中 \(q_{k,G}\) 是“方差加权边际密度”的梯度：
   \[
   q_{k,G}(\hat\theta_k) = \int \Sigma_k(\theta) \nabla_\theta \phi^{(k)}(\hat\theta_k; \theta) dG(\theta)
   \]
   - 相比经典公式，收缩量会根据各坐标的方差大小自适应调整，实现“方差感知”的收缩。

2. **异方差 NPMLE**
   - 通过求解
   \[
   \hat G \in \arg\max_{G \in \mathcal{P}(\mathbb{R}^d)} \frac{1}{K}\sum_{k=1}^K \log f_{k,G}(\hat\theta_k)
   \]
   估计共享先验。
   - 由于协方差依赖参数，NPMLE 支持点不再具有 Ray–Lindsay 的 ridgeline 流形闭式解，因此提出**伪 EM 算法（pseudo-EM）**：
     - E-step：根据当前先验原子计算客户端到各原子的责任权重 \(r_{kj}\)。
     - M-step：用精度加权平均更新原子位置：
       \[
       a_j \leftarrow \left(\sum_k r_{kj} n_k \Sigma_k(a_j)^{-1}\right)^{-1} \sum_k r_{kj} n_k \Sigma_k(a_j)^{-1} \hat\theta_k
       \]
     - **协方差与原子耦合更新**：每次更新原子后，重新在该原子位置计算 \(\Sigma_k(a_j)\)，形成“原子-协方差”交替迭代。
   - 最终个性化估计为后验均值：
   \[
   \hat\theta_k^v = \sum_j r_{kj} a_j
   \]

3. **理论保证**
   - 在**对角异方差 Gaussian 工作模型**下，建立了 NPMLE 的**平均平方 Hellinger 距离**收敛率（非渐近概率界）。
   - 给出了 **oracle 去噪不等式**：VANEB 估计量相对不知道先验的 oracle 后验均值的超额风险为
     \[
     O\left(\frac{(\log K)^{O(d)}\varepsilon_M^2}{n}\right)
     \]
     在离散支持、紧支撑、Gaussian mixture 三种常见先验下可具体化为 \(\tilde O((Kn)^{-1})\) 量级。
   - 用 van Trees 不等式给出 oracle 后验均值的风险下界，说明联邦学习的收益主要来自“学习共享先验”，而非单纯增加本地样本。

### 神经网络扩展

- 针对深度神经网络的非凸、非渐近情形，引入**“共享主干 + 个性化头部”**的分解：
  - **VANEB-Head**：在联邦训练过程中每隔若干轮对客户端头部做一次 NPEB 收缩。
  - **VANEB-FT**：先用 FedAvg 训练共享模型，再让每个客户端本地微调头部，最后对所有微调后的头部做一次 NPEB 收缩。
- 使用基于经验 Fisher 信息矩阵的对角近似方差估计：
  \[
  \hat\Sigma_k = \operatorname{diag}\left(\left[\frac{1}{n_k}\sum_i g_{k,i} g_{k,i}^\top + \lambda I\right]^{-1}\right)
  \]
- 提供两种协方差构造方式：**Direct**（在每个候选原子处直接使用报告的 \(\hat\Sigma_k\)）和 **Coordinate**（拟合坐标级方差函数再在新原子上估值）。

## 实验设计

### 仿真实验

- 三种异构联邦场景，维度 d=3，共享先验为**五条曲线组成的复杂非高斯基底**（三叶结、螺旋线、倾斜椭圆、8字形、Viviani 曲线）。
- 场景：
  1. **二次方差**（样本均值 + 参数二次方差函数）；

  3. **Poisson 回归**（Fisher 信息随参数指数变化，极端异方差）。
- 对比方法：Oracle Bayes、VANEB、固定方差 NPEB、AdaMix、FedAvg、Local-only。
- 评估指标：RMSE，即在给定 (K, n) 下的平均估计误差。

### 深度学习实验

- 数据集：**MNIST** 和 **CIFAR-10**，卷积神经网络（CNN）。
- 异构设置：Dirichlet 标签分布（α = 0.01 / 0.1 / 0.5），并结合聚类协变量偏移（旋转、平移、模糊、对比度、颜色扰动等）。
- 客户端数量：100 / 200 / 500（部分实验 50–1000）。
- 总训练样本固定 50,000，客户端参与率 10%。
- 对比方法：FedAvg、FedAvg+FT、FedRep、FedBABU、FedPer、LG-FedAvg、Per-FedAvg、SCAFFOLD、Ditto、Local Only，以及本文的 4 个变体（VANEB-Direct FT / Coordinate FT / Direct Head / Coordinate Head）。
- 评估协议：
  - **Balanced test**：测试集各类别均匀，考察个性化模型是否仍保留完整类别覆盖能力。
  - **Client-matched test**：测试集与客户端训练标签分布一致，考察局部特化能力。
- 额外设置消融：不同客户端数、不同协变量偏移强度、不同先验原子数（默认 10）等。

## 主要结论与发现

1. **方差感知是有效的**：在二次方差和 Poisson 回归等强异方差仿真中，VANEB 显著优于固定方差 NPEB 和 FedAvg；Logistic 回归中方差信号较弱，需要更大 K 才体现优势。
2. **联邦收益来自先验学习**：风险分解表明，本地独立估计超额风险不随 K 下降，而 VANEB 将超额风险降到 \(\tilde O((Kn)^{-1})\)，说明跨客户端信息共享主要通过 NPMLE 实现。
3. **深度模型实践中表现优异**：VANEB-FT（尤其 Coordinate 版本）在 balanced 评估下几乎全面超越 FedAvg 及其他 PFL 方法（论文称 36/36 个对比中均优于 FedAvg）；在 client-matched 评估中，VANEB-FT 也表现良好，但不如 FedAvg+FT / LG-FedAvg 等强局部微调方法。
4. **两种评估协议的结果差异显著**：balanced 测试反映模型是否保留全局类别覆盖能力，client-matched 测试反映局部标签特化能力；VANEB-FT 在 balanced 上优势最明显，说明经验贝叶斯收缩有助于防止本地微调“遗忘”联邦学到的全局信息。
5. **Direct vs Coordinate 互补**：Coordinate 版本在客户端数据较多时更强，Direct 版本在客户端数很多、本地数据碎片化时更稳定。

## 优点与亮点

- **理论贡献明确**：在现有 NPEB 文献中率先考虑“参数依赖协方差”的异方差情形，并给出广义 Tweedie 公式、Hellinger 收敛率和 oracle 去噪不等式。
- **算法实用**：伪 EM 算法将复杂异方差问题分解为可求解的固定协方差子问题，数值上稳定可用。
- **方法自洽**：从统计模型（M-estimator 渐近正态）到个性化联邦学习之间的桥接自然，且明确区分“跨客户端异质性”和“客户端内异方差”。
- **实验设计有区分度**：引入 balanced 测试协议来揭示很多现有 PFL 方法在保证全局类别覆盖上的不足，这比单纯报告 client-matched 准确率更具洞察力。
- **对比充分**：涵盖优化型（FedAvg/SCAFFOLD）、表示型（FedRep/FedPer/FedBABU）、元学习型（Per-FedAvg）、贝叶斯型（AdaMix 类思想）等方法。

## 不足与局限

- **理论适用域窄**：严格理论仅在**对角协方差**、**渐近高斯**、**中等/大样本量**下成立；深度学习部分缺乏严格理论支撑。
- **深度学习泛化验证不足**：只在 MNIST/CIFAR-10 上验证，未测试更大规模、更复杂、更真实的联邦场景（如文本、推荐、医学影像等）。
- **对方差函数依赖未知分布**：GLM 等场景中协方差函数可能依赖未知协变量分布，论文虽提到客户端可上报估计的协方差函数，但忽略了由此引入的额外不确定性。
- **没有报告算力与运行时间**：不利于复现和评估实际部署成本。
- **统计显著性缺乏**：未提供多次重复实验的标准差或显著性检验，结论的稳健性证据不足。
- **可能存在的偏差风险**：
  - 仿真中五曲线先验条件非常复杂，可能对 NPEB 类方法有利；
  - 神经网络实验固定了骨干网络和超参数（如 atoms=10），未系统研究这些超参数的影响；
  - client-matched 评估中，FedAvg+FT 等方法表现更好，说明 VANEB-FT 并非在所有实际目标下都最优，论文自身也承认这一点。
