## 摘要
生成式推荐受益于推理增强的推断，而潜在推理通过将中间推理过程编码为紧凑的连续表示，为延迟敏感型部署提供了一种高效范式。尽管其高效性，现有潜在推理方法通常依赖于将原始思维链（CoT）轨迹直接蒸馏为潜在表示，假设文本推理痕迹提供了充分的监督。然而，推荐推理轨迹包含多种推理过程，存在冗余表达和不稳定的推理路径，这使得原始CoT监督在学习可迁移的潜在推理表示方面并非最优。为应对这一挑战，我们提出EvoReason，一个自我演化的潜在推理框架，通过原语引导的在线蒸馏，自适应地将显式推理监督与学生的潜在推理空间对齐。首先，EvoReason从高质量智能体推荐轨迹中提取可复用的推理原语，每个原语捕捉一种基本推理行为，并充当结构化教师推理的伪工具。然后，基于这些原语，我们赋予教师原语感知的推理能力，使其能够生成冗余减少且一致性提升的结构化CoT监督。最后，在潜在推理优化过程中，EvoReason引入一种自我演化的在线蒸馏机制，其中原语引导的推理过程根据学生的潜在推理结果进行演化。通过这种闭环协同演化，策略更新持续改进潜在推理行为，并根据由此产生的潜在推理结果进行优化，从而实现逐步更好对齐的CoT监督和更有效的推理迁移。

## Abstract
Generative recommendation benefits from reasoning-enhanced inference, and latent reasoning offers an efficient paradigm by encoding intermediate reasoning processes into compact continuous representations for latency-sensitive deployment. Despite its efficiency, existing latent reasoning approaches typically rely on directly distilling raw chain-of-thought (CoT) trajectories into latent representations, assuming that textual reasoning traces provide sufficient supervision. However, recommendation reasoning trajectories contain diverse reasoning processes with redundant expressions and unstable reasoning paths, making raw CoT supervision suboptimal for learning transferable latent reasoning representations. To address this challenge, we propose EvoReason, a self-evolving latent reasoning framework that adaptively aligns explicit reasoning supervision with the student's latent reasoning space through primitive-guided on-policy distillation. First, EvoReason extracts reusable reasoning primitives from high-quality agentic recommendation trajectories, where each primitive captures an essential reasoning behavior and serves as a pseudo-tool for structured teacher reasoning. Then, based on these primitives, we equip the teacher with primitive-aware reasoning capabilities, enabling it to generate structured CoT supervision with reduced redundancy and improved consistency. Finally, during latent reasoning optimization, EvoReason introduces a self-evolving on-policy distillation mechanism, where the primitive-guided reasoning process evolves according to the student's latent reasoning outcomes. Through this closed-loop co-evolution, policy updates continuously improve latent reasoning behaviors is refined according to the resulting latent reasoning outcomes, enabling progressively better-aligned CoT supervision and more effective reasoning transfer.

## 1. 核心问题与整体含义（研究动机与背景）

- **背景**：大语言模型（LLM）的推理能力（如 CoT、DeepSeek-R1 等）已被引入推荐系统，用于从用户历史交互中推断复杂隐含偏好。生成式推荐将推荐任务转化为目标 ID 的自回归生成，而**潜在推理（latent reasoning）** 将中间推理过程编码为紧凑的连续表示，以避免显式 CoT 带来的高推理延迟，适用于延迟敏感的生产环境。
- **核心问题**：现有潜在推理方法（如 LASAR）通常将**原始 CoT 轨迹直接蒸馏**到潜在表示中，但推荐场景中的推理轨迹存在两点缺陷：
  1. **冗余表达**：同一推理行为有多种语言实现，干扰潜在 token 学习可复用的推理结构；
  2. **路径不稳定**：自由形式的 CoT 推理模式多样、不一致，难以迁移到紧凑的潜在表示。
  
  另外，现有方法依赖**静态、离线生成的推理监督**，无法随学生模型（latent reasoner）能力的演化而自适应调整。
- **整体意义**：论文提出让显式推理监督与学生的潜在推理空间形成**闭环协同演化**，从而把“推理能力”更有效地迁移到潜在表示中，同时保持推理阶段无显式 CoT 的高效率。

## 2. 论文提出的方法论

- **总体框架**：EvoReason 是一个三阶段自演化框架：
  1. **推理原语发现（Primitive Discovery）**；
  2. **原语感知教师的监督微调（Primitive-Aware Teacher SFT）**；
  3. **自演化在线蒸馏（Self-Evolving On-Policy Distillation）**。

- **阶段 1：自我演化的推理原语发现**
  - 使用具备 ReAct 式工具调用能力的智能体教师（QwQ-32B）收集高质量推荐轨迹，轨迹中包含证据提取、偏好分析、意图推断、决策等中间行为，形成经验池 \( \mathcal{D}_{reason} \)。
  - 从经验池中归纳出可复用的**推理原语（reasoning primitive）库** \( \mathcal{P}=\{p_1,\dots,p_K\} \)，每个原语类似一个 Python 风格函数，包含输入参数、结构化推理过程、输出格式约束，充当教师推理的“伪工具”。
  - 原语库**持续演化**：用当前潜在推理器产出的成功/失败行为反馈来更新原语库 \( \mathcal{P}_{m+1} = \text{Update}(\mathcal{P}_m, \mathcal{R}_{latent}) \)，从而让后续 CoT 监督逐步适配学生的最新推理能力。

- **阶段 2：原语感知教师 SFT**
  - 用原语库构造结构化 CoT 数据：\( c = [\langle p_1\rangle, c_1, \langle p_2\rangle, c_2, \dots, \langle p_K\rangle, c_K] \)，即先调用原语再输出对应推理内容。
  - 在数据集 \( \mathcal{D}_{sft}=\{(x_i,c_i,y_i)\} \) 上以标准因果语言建模目标微调教师策略 \( \phi \)，使教师学会调用原语生成结构化、冗余更少、一致性更高的推理轨迹。

- **阶段 3：自演化在线潜在推理蒸馏**

## 6. 主要结论与发现

- **推理型方法整体优于传统序列/生成式推荐**：说明显式/隐式推理能更好地捕捉用户偏好和意图。
- **密集 CoT 监督比结构正则化、RL 稀疏奖励等监督方式更有效**：潜在推理需要密集的语义级 token 监督。
- **EvoReason 在所有数据集和指标上显著领先最强基线 LASAR**：例如 Beauty 上 Recall@5 相对提升约 +17.9%（0.0724 vs 0.0613），NDCG@5 +27.4%；Sports 上 Recall@5 +17.1%；工业数据集 Recall@5 +15.4%。

- **自演化机制有效**：训练中 EvoReason 的成功率更早上升且持续领先 LASAR；自演化变体能更快减少原语调用次数，说明原语库逐渐变得更精炼、更适配学生能力。
- **冷启动缓解**：EvoReason 对非活跃用户的相对提升幅度最大，说明推理能力迁移有助于缓解冷启动问题。
- **跨域与效率**：跨数据集泛化优于 LASAR；推理延迟远低于显式 CoT 方法（OneRec-Think），仅比一般不推理的 TIGER 稍高。

- 评估指标口径偏窄：离线实验仅使用 Recall@5/10 与 NDCG@5/10，未报告 AUC、Hit Rate、MRR 等序列推荐常用指标，也未涉及推荐结果的多样性、新颖性、品类覆盖或公平性，考察维度较为单一。
- 对潜在表示的可解释性缺乏直接证据：论文宣称潜在 token 承载了“推理状态”，但只在任务层面验证了效果，没有通过探针实验、中间状态可视化或逐步反演来分析潜在 token 是否真的编码了与推荐决策相关的语义信息，这削弱了“潜在推理”概念本身的论证强度。
- 代码与数据未开源：工业数据集不公开可以理解，但公开数据集上的实现细节、原语库示例和训练配置也未能完整提供，考虑到复现门槛较高，这限制了该工作被后续研究直接利用的可能性。

## 9. 总体评价与启示

- **对推荐系统领域**：该工作最重要的启示不是“又一个更强的推荐模型”，而是提出了一种将“可迁移推理能力”编码进紧凑潜在表示的闭环训练范式。它将传统 CoT 教导、在线强化学习、知识蒸馏三者组织成自洽的协同演化流程，为延迟敏感场景下的生成式推荐提供了新的设计空间。
- **对潜在推理研究**：论文明确指出“自由形式 CoT 不适合直接蒸馏到潜在空间”，并通过推理原语将其结构化，这是一个值得推广的判断；同时，教师与学生共享主干、依赖学生当前潜在状态做 stop-gradient 再推理的思路，也为后续“教师如何适应学生”提供了可借鉴的低成本方案。
- **对生产落地**：在线 A/B 测试中的广告主价值与平台收入提升表明，潜在推理不是仅停留在学术基准上的技巧，而是能真实改善商业指标的技术手段；同时 0.56 s/样本的推理延迟证明了它在真实流量下具备可行性。
- **局限中的机会**：统计显著性缺失、最新基线缺失、超参数敏感性不足等问题，恰为后续研究者提供了明确的补强方向——在更标准化的环境下复现、扩充基线、补充探针实验，都将是高价值的后续工作。
- **总体判断**：在“将复杂推理迁移到高效潜在表示”这一目标上，EvoReason 从动机、方法到实验链条都较为完整，工业验证尤其加分。但方法的高度依赖 LLM 教师与动态原语库、以及不透明的工业设置，使其更像一个“工业界可复现、学术界较难完全复现”的工作。若未来能开源核心模块并补充更多统计证据，该工作的学术影响力会进一步提升。
