## 摘要
生成式推荐（GenRec）代表了一种有前景的范式，通过将物品编码为紧凑的语义ID（SID）并在不同推荐场景中通过下一词预测建模用户行为，取得了显著的实证成功。将这种范式扩展到跨域推荐具有挑战性，因为统一模型必须适应不同领域中的异构物品语义和行为模式。现有方法通常依赖全局共享表示或轻量级域自适应，这可能不足以在不同语义粒度上建模异构模式。为解决这些挑战，我们提出了HD-Rec，一个用于跨域推荐的统一生成式框架。HD-Rec采用分层域感知量化器，利用全局共享的粗粒度码本和自适应路由的细粒度码本构建语义标识。它还引入了一个域自适应稀疏混合专家模块，结合了持续激活的共享专家和动态选择的专用专家。为了提高多令牌物品表示的一致性，我们开发了一种跨粒度路由一致性目标，该目标将令牌级路由决策规范化为其物品级共识。在三个公开的跨域推荐基准上的实验表明，HD-Rec持续优于竞争性的序列、生成式和跨域推荐基线。

## Abstract
Generative Recommendation (GenRec) represents a promising paradigm that achieves remarkable empirical success by encoding items as compact Semantic IDs (SIDs) and modeling user behavior via next-token prediction across diverse recommendation scenarios. Extending this paradigm to cross-domain recommendation is challenging because a unified model must accommodate heterogeneous item semantics and behavioral patterns across domains. Existing methods commonly rely on globally shared representations or lightweight domain adaptation, which may provide insufficient capacity for modeling heterogeneous patterns at different semantic granularities. To address these challenges, we propose HD-Rec, a unified generative framework for cross-domain recommendation. HD-Rec employs a hierarchical domain-aware quantizer that constructs semantic identifiers using globally shared coarse-level codebooks and adaptively routed fine-level codebooks. It further introduces a domain-adaptive sparse mixture-of-experts module that combines a continuously activated shared expert with a dynamically selected specialized expert. To improve the coherence of multi-token item representations, we develop a cross-granularity routing consistency objective that regularizes token-level routing decisions toward their item-level consensus. Experiments on three public cross-domain recommendation benchmarks show that HD-Rec consistently improves over competitive sequential, generative, and cross-domain recommendation baselines.

## 2. 论文提出的方法论

### 2.1 核心思想

论文的核心哲学是**层次化建模**：在物品表示层面，粗粒度语义用全局共享容量编码，细粒度语义用自适应路由的专用容量编码；在模型容量层面，将始终激活的共享专家与按输入动态选择的专用专家结合；在训练目标层面，通过跨粒度路由一致性约束使同一物品的多个语义token保持路由决策一致。

### 2.2 关键技术细节

**（1）层次域感知量化器（Hierarchical Domain-Aware Quantizer, HDQ）**

HDQ对RQ-VAE进行改造，将L层量化分阶段设计：

- **粗粒度层（第1至L−1层）**：全部使用全局共享码本（shared codebooks），通过最近邻查找（最小化欧氏距离）渐进分解物品的粗粒度语义，逐步更新残差 r_l = r_{l−1} − c_l。
- **细粒度最终层（第L层）**：引入K个可路由的码本（codebooks）。通过轻量路由器g_φ对上一层的残差 r_{L−1} 计算路由logits，经Gumbel-Softmax获得可微的离散路由决策，使用straight-through estimator在forward中取top-1码本索引、在backward中传递软概率梯度。最后在选定的码本内执行最近邻查找。
- **最终量化表示**：聚合所有浅层共享码字与最终层路由码字，经解码器重构原始输入。

**训练目标**：联合最小化重构损失L_rec、码本损失L_cb（含stop-gradient）、承诺损失L_com，以及路由负载均衡正则L_balance（防止路由崩溃，鼓励均匀使用K个码本），整体为加权求和。

**（2）域自适应稀疏MoE（Domain-Adaptive Sparse MoE, DAS MoE）**

在Transformer骨干中替换标准FFN层：

- 每层包含**1个始终激活的共享专家E_shared**和**K个专用专家{E_1, …, E_K}**；
- 轻量门控网络 W_gate 将token表示 h_t 映射为K维路由logits，通过top-1选择唯一的专用专家；
- 最终输出为共享专家与所选专用专家输出之和：`MoE(h_t) = E_shared(h_t) + E_{k*}(h_t)`。

此设计在保持稀疏计算的前提下，为模型提供条件性容量分配能力。

**（3）跨粒度路由一致性学习（Cross-Granularity Routing Consistency Learning, CRCL）**

动机：同一物品的多个语义token构成其完整语义ID，若token级路由各自独立，可能导致同一物品的不同token被分配到差异很大的专家。为此：

- 对物品的L个token嵌入做mean pooling得到物品级表示 h_avg；
- 经同一门控网络得到物品级路由分布 P_item = softmax(W_gate h_avg)；
- 每个token保留自己的局部路由分布 P_token；
- 以KL散度惩罚token级分布与物品级分布之间的偏离，保留token级灵活性同时鼓励组内一致性。

**总训练目标**：L_total = L_ntp + λ1·L_consistency + λ2·L_balance。

### 2.3 训练流程

采用两阶段流水线：第一阶段单独训练层次域感知量化器（AdamW，lr=1e-3）；第二阶段训练整个推荐模型（T5作为骨干，lr=1e-4），推理时使用beam search。

## 6. 论文的主要结论与发现

1. **HD-REC在所有域和指标上均优于全部基线**：与最强基线相比，H@10相对提升在Sports和Electronics上尤为显著（分别达17.6%和16.3%），在Phones上提升9.9%，整体一致优于既有序列、生成式和跨域推荐模型。
2. **层次化量化是有效的**：去掉HDQ（仅用标准RQ-VAE）导致明显性能下降，说明“全局共享粗粒度 + 自适应路由细粒度”的设计优于单一共享码本；
3. **域自适应稀疏MoE有效**：替换为稠密FFN时性能下降，说明共享容量与按输入选择的专用容量结合更优；
4. **CRCL带来显著的组内路由一致性提升**：Routing Variance降低约6.0倍，且性能同步提升，验证了组内路由一致性对多token物品表示学习的重要性；
5. **额外推理开销可忽略**：HD-REC每测试样本仅比TIGER慢约2ms（相对开销约2.0%–2.5%），效率可接受。

## 7. 优点

- **问题切入精准**：准确识别了跨域GenRec中“共享vs专用容量”的核心矛盾，并给出了一套对应三阶段解决方案（量化层、MoE层、训练目标），逻辑自洽；
- **层次化量化设计有启发性**：将量化层次与语义粒度绑定（粗粒度共享、细粒度路由）在思想上是自然且有说服力的；路由码本上使用Gumbel-Softmax配合straight-through estimator，兼顾了离散性和可微性；

## 8. 不足与局限

### 8.1 实验覆盖的局限

- **仅评估两域设置**：论文在Limitations中明确承认，实验主要聚焦于成对的两域CDSR场景，未验证方法在大规模多域（3个以上域）下的扩展性和稳定性。实际推荐系统往往横跨更多域；
- **消融实验仅在一个数据对上报告**：组件级消融只在Clothing-Sports上验证，其他数据对上的贡献未展示，降低了消融结论的泛化可信度；
- **缺少在线/动态评估**：离线基准忽略了动态物品目录、用户兴趣漂移、域分布变化和在线反馈回路等真实部署条件。

### 8.2 方法本身的局限

- **依赖物品元数据的质量和语义对齐**：HD-REC依赖物品内容嵌入（如标题、描述等）和语义ID tokenization，当元数据有噪声、不完整或与用户真实偏好信号弱对齐时，性能可能下降；
- **没有直接量化“语义分离”效果**：论文承认本研究未直接度量表示专业化/分离程度（representation disentanglement），依赖的是下游推荐指标作为间接证据；
- **路由专家缺乏可解释性**：路由决策是否对应有语义含义的专家未做分析，K个码本/专家的语义角色未被揭示；
- **未讨论公平性和隐私问题**：论文在Limitations中也承认此点，未研究生成式CDR中如公平性和隐私保护的实际问题。

### 8.3 方法论的潜在偏差风险

- **性能提升可能部分来源于模型容量而非设计本身**：Ablation中“Expand Last”变体部分排除了“容量增加”解释，但未与参数量匹配的稠密模型做充分对比，因果关系仍需进一步隔离；
- **两阶段训练依赖设计的稳健性未充分讨论**：量化器阶段的误差会传导至推荐模型，潜在误差传播问题未深入分析。
