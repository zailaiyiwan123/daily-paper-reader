## 摘要
长期个性化对话代理必须随着用户人设的演变追踪其偏好。现有的记忆系统能够良好地组织过去的事件，但将人设存储为扁平档案，脱离于支撑这些档案的事件。这种松散耦合导致了记忆-人设有效性差距和人设感知检索差距。我们提出了PGMem，一种异构的人设-记忆图，通过类型化的来源边和证据边连接事件节点和人设节点，使每个人设信号都可追溯到支持或修正它的事件。在检索时，PGMem从查询相关的种子节点扩展，并根据证据有效性对信号进行排序。在三个采用小语言模型骨干的基准测试中，PGMem持续优于基于摘要、人设感知、图结构和代理式记忆的基线，并且随着上下文增长其性能提升。PGMem的源代码可在https://github.com/wonjunchoi23/pgmem/获取。

## Abstract
Long-term personalized dialogue agents must track user preferences as their personas evolve. Existing memory systems organize past events well, but store personas as flat profiles detached from the events that justify them. This loose coupling leads to the memory-persona validity gap and the persona-aware retrieval gap. We propose PGMem, a heterogeneous persona-memory graph that connects event and persona nodes through typed provenance and evidence edges, keeping each persona signal traceable to the events that support or revise it. At retrieval time, PGMem expands from query-relevant seeds and ranks signals by evidential validity. Across three benchmarks with small language model backbones, PGMem consistently outperforms summary-based, persona-aware, graph-structured, and agentic memory baselines, and improves performance as the context grows. The source code of PGMem is available at https://github.com/wonjunchoi23/pgmem/

## 1. 论文的核心问题与整体含义（研究动机和背景）

长期个性化对话代理（Lifelong Personalized Agents）需要在持续的交互中追踪用户偏好，并随着用户人设的演变进行适应。论文指出现有记忆系统存在两个结构性缺陷：

- **记忆-人设有效性差距（Memory–Persona Validity Gap）**：在记忆构建阶段，现有方法很少将情景记忆（episodic memory）和人设信号作为耦合证据存储，导致无法表示人设信号为何出现、后续事件如何支持它、或者新信号如何修正旧偏好。例如，用户先表达喜欢热闹的酒吧和啤酒，后来决定戒酒，再后来提到"酒吧的氛围让戒酒变得更难"——这一最后发言隐藏着人设信号，但若仅存为表面层面的片段，就无法验证用户当前的戒酒状态。
- **人设感知检索差距（Persona-aware Retrieval Gap）**：在查询阶段，现有方法严重依赖查询与记忆之间的表层相似度，忽略潜在的人设状态。这会导致返回与字面查询高度相似但直接冲突于用户当前人设的历史片段，而错过对生成人设一致回答至关重要的隐含、弱匹配上下文。

论文将终身个性化对话首次形式化为"基于证据的人设管理"（evidence-grounded persona management）问题，而非仅仅是用户档案的积累。

## 2. 论文提出的方法论：核心思想、关键技术细节、公式或算法流程

### 核心思想
提出 **PGMem**，一种**异构人设-记忆图**（heterogeneous persona-memory graph），通过类型化的来源边（provenance edges）和证据边（evidence edges）将事件记忆与人设信号紧密耦合。人设信号只有在对话证据支撑并且与后续交互保持一致时，才能指导回答生成。

### 技术细节

**（1）图结构：双层节点 + 两类边**

**节点类型（事件层与人设层）：**
- 事件层：**Context 节点**（存储原始轮次话语）、**Episode 节点**（对连续对话块的摘要）
- 人设层：**State 节点**（短期人设信号，如当前偏好、约束、目标、立场）、**Trait 节点**（由累积对话抽象出的稳定特质）

**边类型：**
- **Source 边（Esrc）**：编码跨抽象层级的来源关系，即高层节点由低层节点构建而来。
- **Evidence 边（Eevi）**：带类型标签的 evidential 关系，包括：
  - ⊕（SUPPORT）：一致/互相强化
  - ⊖（CONTRADICT）：明确冲突
  - ⇝（SHIFT_TO）：时间有序的方向性更新，新信号取代旧信号
  - ∅（IRRELEVANT）：无关对被标记后不再重复判断

**（2）内存图构建（Update 算子 U）**
- 每轮对话生成一个 Context 节点；若携带人设信号，提取 State 节点。
- chunk 边界处将 Context 节点汇总为 Episode 节点。
- 每 B 个 chunk 利用累积的 Context、State、Episode 节点提取 Trait 节点。
- 分**局部更新**（新节点与最近/已有候选配对判断关系）和**离线更新**（检测远距离、先前未连接节点之间的长程关系）两个阶段。
- 分类提示使用固定的决策优先级，不确定的配对归为 IRR，避免引入检索噪声。

**（3）记忆检索（Retrieval 算子 R），三阶段流程**

**Stage 1: 种子检索（Seed Retrieval）**
- 结合嵌入余弦相似度 `sem(q, v)` 和词法重叠 `ov(q, v)` 打分：`ϕ(q, v) = w_sem · sem(q, v) + w_ov · ov(q, v)`。
- 对四类节点分别选取 top-k 种子；利用 Active Persona Set（APS）保留高记忆优先级（RECALL_PRIORITY=HIGH）的 State 节点。

**Stage 2: 证据引导的图扩展（Evidence-Guided Expansion）**
- 从种子沿证据边进行带符号路径遍历；路径符号遵循乘法组合律：`s+ ∘ s+ = s+`，`s+ ∘ s− = s−`。
- s+ 边允许继续遍历，s− 边终止路径；受跳数上限 H 约束。
- 通过这种方式，可以找到与查询表面相似度低但经由证据边相连的人设信号。

**Stage 3: 有效性感知的最终组装（Validity-Aware Final Assembly）**
- 先移除被替代（SFT）的源节点（若其目标节点也在池中）。
- 计算有效性分数（平滑常数 α）：

```
val(v) = (|S(v)| + α) / (|S(v)| + |C(v)| + 2α)
```

- 最终排序分数：`ψ(q, v) = λ · val(v) + (1 − λ) · ϕ(q, v)`（默认 λ = 0.5），选取固定预算下的 top 节点序列化到生成提示中。

1. **PGMem 在全部三个基准和两个 SLM 骨干下均取得最佳表现**：ImplexConv 上超过最强基线最多 29%；PrefEval 上最高超出 59%。

4. **效率可接受**：PGMem 构建成本低于 A-MEM 和 THEANINE，QA token 消费仅高于最便宜的摘要式基线，低于代理式基线和全历史基线，LLM 调用次数少（每查询 1 次）。

6. **人类验证表明 LLM-judge 结果可信**：人工评分的排名与 LLM-judge 一致，PGMem 得分最高。

## 8. 不足与局限

- **证据边分类的可靠性问题**：人工验证显示 CON（⊖）和 SFT（⇝）两种关系类型的标签准确率仅为 36% 和 52%（SUP 和 IRR 为 80% 和 84%）。这表明 SLM 骨干难以准确判断"真正的冲突/替代"与"无关"之间的微妙边界。虽然论文指出这两种边在图中占比很小（CON 仅 49.3/session，SFT 仅 125.2/session），且错误边数有限，但这仍是准确性隐患。
- **合成数据局限**：所有实验仅基于合成 benchmark，缺乏真实世界中组织化、隐私保护下的长期人设演变对话数据。真实场景的人设信号更加模糊、多变。
- **边类型粒度有限**：当前证据边分类学仅覆盖核心证据极性（support/contradict/shift），缺少更细粒度的认知维度（如信念修正的认知模型），未来可用 COMET-Atomic 2020 等常识知识图谱做更细粒度的有效性推理。
- **长期生命周期的维护策略未解决**：跨数月或数年的交互会积累远超当前上下文规模的节点和边，需要高效的剪枝、整合和衰减策略。限制部分提到低有效性节点和 SFT 节点可作为自动剪枝候选，但将其留作未来工作。
- **数据权利与敏感性**：在医疗等敏感领域中用户数据权利要求更高的删除/遗忘能力；论文指出 State/Trait 节点的人类可读性有利于单点删除，但未做系统验证。
- **生成侧局限**：案例分析显示"near-miss"失败模式——信号被检索到但回答未在实质层面体现该信号。这是生成侧（SLM 能力）的限制而非检索失败。
- **更大模型下的相对优势减弱**：在 4B 骨干下 PersonaMem 上 A-MEM 反超，说明 PGMem 的优势（尤其是对 SLM 而言）部分源于将个性化负担从骨干能力转移到记忆结构；在能力更强的模型上，基线受益更大。
- **未报告训练/预训练开销**：论文未给出任何端到端训练（如果有的话）的算力消耗，只报告了推理与记忆构建成本。
